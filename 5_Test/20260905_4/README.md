# 20260905_4：有证据约束的时序与接触动力学试验

继续使用冻结水文及 mineral lifetime + slow-water N 两库存，不添加站点参数。
本阶段代码独立于正在运行的 _3 核心文件；完成梯度和守恒验证后才能拟合。

预先限定的试验轴：

- CENTRAL 月初输入基准与月内均匀输入/作物需求分配。月总输入不变。
- 原始产品已提供的 EARLY/CENTRAL/LATE 月历，全部年份均有覆盖。
- 两个全局系数调节接触 hazard：训练期标准化的 log(1 + 上层储水/mm)
  与 log(1 + 向下层渗漏/mm/day)。两者全部来自水文接口。
  系数先验 N(0, 0.15²)，边界 [-1,1]；不增加新的氮池或自由时间曲线。

公式为 p = 1 - exp[-exp(a_reach + beta log(contact) + eta_U z_U + eta_P z_P)]，
无 contact 时仍严格 p=0。z 的标准化只用该折训练年份和训练河段。
这检验同一相对接触比下绝对储水/补给条件是否提供额外信息。

依据：_1 文献登记中的 HYPE / mHM-Nitrate 水路径与状态依赖机制，以及
_2 固定参数的日历重分配差异审计。该依据支持可检验的假设，并不证明本流域有效。
任何组合最多包含两项独立通过开发 OOF 的改动；禁止用测试年份选训练起点。

温度：_1 已核实完整气温来源，但气温不是水温；只有新的 OOF 残差诊断支持
独立作用时才开放单独温度试验。WWTP 与 PON 分支保持关闭。

当前状态：四种日输入/动力学组合均通过有限差分、未来输入隔离及完整质量守恒验证，
峰值RSS约2.04 GiB；80次单改动拟合均已完成并达到收敛门槛。

新的条件残差探针中，上层储水/下渗在四个年份均提供增益，等站残差MSE总体下降约21.3%。
该探针只是机制诊断，不是TN产品精度。气温探针虽然总体增益约5.1%、系数符号一致，
但只有2/4年达到预先定义的2%增益，未通过3/4年重复性条件，因此本轮不新增温度参数。
具体判断见 `reports/temperature_mechanism_decision.json`，不能解读成温度没有作用。
