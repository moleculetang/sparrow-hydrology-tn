## 已完成的首个外层结果（非全阶段结论）

REACH_O0 已完成，内层选择 contact_dynamic。其24个留出站点、953条观测的
外层单站NSE中位数为 -1.2872，旧对照为 -2.2786；但是q25从 -6.4358
降至 -9.6180，平均站点log-RMSE从0.3143升至0.3394。
因此本折显示中位站点改善与较差站点退化同时存在，不能据此宣称空间非退化通过。
新模型站内时间相关中位数为 -0.0168，预测/观测标准差比中位数为0.4943；
旧对照分别为0.0716、0.8935。绝对均值偏差中位数几乎相同（约0.456mg/L）。
这支持减少部分错误波动的解释，尚不支持已捕捉到观测时间变化；误差分解只用于诊断，
不产生经过观测均值或残差校正的预测。
`reports/nested_selection_audit.json` 已逐值追溯所选起点、内外层预测及独立重算指标。
其余外层已按原注册候选集执行，首折外层效果未用于裁剪后续候选。
