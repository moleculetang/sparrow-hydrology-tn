# 2021 日TN、四小时原始读数与日月连接样例

[下载一个ZIP](tn_daily_4h_2021.zip)。这是用户明确授权的观测补充，不包含整个工程、全部月报或2022—2024评价标签；没有修改现役训练。解压后直接读取`hf_daily.parquet`，或从原始快照重新选择观测支持。

## 覆盖及身份

本包优先提供2021：唯一时刻记录覆盖北京时间 **2021-06-17 08:00—2021-12-30 12:00**，15个站点身份、2,653条TN唯一时刻记录；现成日表为14站651个站日。它不是完整连续半年记录，逐站起止、读数与日数见`coverage.csv`。一个站点虽有原始读数，但没有符合既有读数资格的日均，保留其原始记录及站表，不造日值。本次所定位四小时档案始于2021年6月；没有找到2021年以前的同源HF档案，不用月值复制成日值。后续年份暂未上传，开发／保留验证如何划分仍由接收方依据覆盖确认。

时间为`Asia/Shanghai`（UTC+8、北京时间，无夏令时）。`monitoring_time`是行内监测时刻；`capture_time`是网页快照采集时刻，二者不能替换。原行可能只写月日，既有`time_rule`、`explicit_year`和证据键保留；53条缺时刻行仍在原始层。不得将文件名时间当采样时间。

站名统一替换成TN001—TN015，跨日表、原始表、唯一时刻表、站表及月样例使用同一键。`station_id`保留既有稳定数据库ID，**不是官方站码**；未找到官方站码的字段`official_station_code`为空。可用`station_key`或稳定`station_id`连接，原名对照仅保留本地。经纬度、河段及沿程位置仍保留供空间核验，因此这是名称去标识，不是强地理匿名。

| `TN_original_fields_2021.csv` | 从原CSV逐字提取的监测时间、TN、水质类别、站况及原中文字段名；仅断面名替换为匿名键，并附文件/行号。与上述原始层逐行对应。 |

原始层有307条TN解析缺测：220个`*`、87个`--`，原符号未改。站况有正常3,029条、维护117条、不具备运行条件42条；这些记录都保留。没有将缺日期创建为全零行。

现成日表沿用已有规则：读数需有限、非负、非删失、正常状态且无未决冲突，统计高值不按异常标记删除；日均本身保留所有有合格读数的日，`day_coverage_eligible/eligible`只在独立时刻数≥4且首末跨度≥12小时成立。不提前删除不合格日；`read_count`是本档案可用读数数量，不等于仪器真实完整日计数。快照重复不算额外采样。全原始层允许接收方另行评估资格，不能把采用层当未处理原值。

采用表的既有重复规则优先最后采集的正常数值，否则最后可解析非负有限数值；同采集时刻冲突保留标记，不求平均。完整时间/重复/空间处理来源为本地auto_4h档案及冻结观测合同，本补充没有重新执行清洗或以模型残差删样本。

用户已确认月报来自自动监测、按有效读数算术均值理解。原样例没有月有效读数次数或明细，现有HF采集也有大量缺口，因此本包不先认定日月冲突，也不认证等日月均等于官方月报。请先按同站、重叠时段和有效读数支持核查；不应把这几个月同时用于开发选择和保留评价。

## 可运行核验

安装pandas、numpy、pyarrow后，解压进入目录，执行`python verify.py`；也可在仓库根目录执行`python observations/tn_daily_4h_2021/verify.py`。核验包内SHA256、站键连接、原缺测符号、原层与采用读数连接、日均/计数/跨度独立重算、月样例范围及缺码留空。

本地另已将全部3,188个原始TN、原时间和站况符号逐字对照220份原CSV，均一致；日均及有效读数计数独立重算误差为0，当前冻结日表与此前ML日表一致。没有因先前常数预测聚合修复而改动原始日观测。公开核验能检查包内一致性和源哈希记录，无法从未公开全国原文件再次计算原文件SHA256。资料沿用原提供方条款；数据上传与训练、数值充分或真实TN改善是不同事项，NSE不适用于本包字节/输入核验。
