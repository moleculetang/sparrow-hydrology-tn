# sparrow-hydrology-tn

## D29 / LAND1 研究候选

[共同平台、数值修正与全域训练策略审阅包](experiments/d29_land1_20260927/README.md)包含 LAND0 兼容实现、LAND1 候选、2016—2024 月报与高频辅助目标、完整历史数值核、合成测试和专家报告。

[2026-09-28 全量训练及验证审阅包](experiments/d29_training_20260928/README.md)是基于上述候选的后续实验：32 条路径均保存合法检查点，24 个配置仅按训练目标选点；包含训练期与 2023/2024 留出期 NSE、路径释义、实际运行代码、合成测试及独立复核。本包作为叠放 PR 依赖前述 LAND1 PR。

前一审阅包记录的是训练前的数值验收状态；后续训练和留出 NSE 以 2026-09-28 审阅包为准。CPU/GPU 实测没有支持启用当前局部 CUDA 映射。私有监测和驱动数据不在本仓库，审阅包不会自动替换生产模型或启动训练。
