# 城镇污水处理厂：汇总氮负荷与核心拟合方法

来自20260817_9负荷产品及20260818_3历史敏感性实验。本包仅公开省级／河段汇总、时间折参数、核心计算函数和审计。其他详细材料保留本地，尚未获自动审批放行。没有原始河流水质监测。

## 污水厂在模型中的角色

它是直接入河的外部氮质量输入，没有单独的污水厂待拟合倍率。旧浓度方程为

`C = 1000 × (eta_quick × M_quick + eta_gw × M_gw + M_WWTP) / V_water`。

质量kg N、水量m³、浓度mg/L。WWTP不乘面源eta，不进入土壤库存或面源运输时间分布，回流水量关闭。每个候选独立拟合面源快／慢eta，范围0—1、初值(0.8,0.8)；旧P2读出层另含对数偏移。P1/P2在此指旧读出层，不能与新过程学习家族混用。

拟合使用log1p浓度残差、eta先验系数1、偏移惩罚12，TRF最小二乘求解；核心函数在legacy_readout.py。污水负荷不是通过河流TN逐项调出来的。合成回归只验证软件，不是水质效果。

## 汇总输入量的来源和时间分配

Chen等2019 [DOI:10.1021/acs.est.8b07352](https://doi.org/10.1021/acs.est.8b07352) 提供2012年模型估算的TDN参考量。Wang等2022 [DOI:10.1038/s41597-022-01439-7](https://doi.org/10.1038/s41597-022-01439-7) 提供2006—2019年省级终端水体TN变化；其TN由论文模型出水N₂O按官方因子恢复，不是独立现场TN测量。

公开重建器使用河段×省份汇总参考量A、相对2012的省级变化F及预设溶解比例f：`L_year = A × F / f × 1000`。A单位t N/year。三个研究情景f=1、0.9、0.8不由河流TN拟合；f=1为TDN等于TN的下界近似。月量按公历日数分配：`L_month = L_year × days_month / days_year`，不制造季节循环。

## 公开文件

- data/：113个河段×省份汇总参考单元、4,704行河段年量、56,448行河段月量，覆盖112个有记录河段；省级时间因子及活动核查。
- fit/candidate_fold_readout_parameters.parquet：240条时间折参数／求解器回执。
- fit/wwtp_scenario_registry.parquet：五个情景的230河段月网格、局地和累计氮量；PS0为显式关闭点源对照。
- evidence/：原负荷闭合、单位、来源非重叠与历史决策记录。
- rebuild.py、legacy_readout.py、verify.py：汇总重建、核心拟合及只读验收。
- manifest.json、verification.json：公开文件字节哈希与本次核验。

PS1为TDN下界，PS2为旧输入质量筛选敏感性，PS3/PS09为f=0.8/0.9情景。详细输入选择方法保持本地，不在本包重做其身份认证。

## 运行与边界

安装requirements.txt依赖后运行 `python verify.py`。重建全部三种情景的河段年／月量，核对2012参考、闰日、质量闭合和参数表，并执行已知合成读出检查。汇总运算顺序与旧逐项运算不同，按原1e-6 kg质量门核对，不能冒称逐位一致。

正式旧时间验证仅2018/2019；2020之后输入没有补齐。历史判据不能直接解释为当前NSE收益。旧读出在无水时返回0、缺失点源列补0，这是保留的历史实现限制，不符合当前无水浓度不可定义和未知输入不补零的合同，不可直接移植。

当前20261008_1的44条施肥时序路径没有启用WWTP来源或WWTP参数。本次只发布历史汇总材料，不改变训练代码、资料或参数。未来接入需要完整目标年份、质量和空间支持验收，不能复制旧年份或用零填缺项。

第三方资料遵循原提供方条款，本仓库不作新的许可授权；这些量仍为研究情景，不认证实际排放记录。
