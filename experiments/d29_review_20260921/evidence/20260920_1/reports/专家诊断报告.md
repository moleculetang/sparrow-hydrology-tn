# 专家诊断报告 —— `20260920_1`

> 判决：**`MOBILE_POOL_MAPPING_LIMITED`**，主臂 `P-upper`，五门 **0/5**，
> 下一轮唯一自由度 **`k_m`**。
> 本报告只做一件事：**说清楚这一轮看到的失败形态是什么、不是什么。**

---

## 一、诊断的结论，一句话

**不能把长期 legacy 库存直接等同于 mobile N。**

这不是"双路径移动水浓度机制失败了"。本轮**没有**能力回答那个问题——
**在把"可动性映射"这一层单独判过之前，看不到路径浓度结构是否成立。**
按 §2.6 P1 的规定，主臂标记 `UNIT_SCALE_LIMITED`，
**它的事件门失败是时间尺度事实，不是机制证据。**

## 二、失败的形态：**水平暴涨、方差暴涨、事件比反而下降**

这不是"结构没能力产生振幅"该有的样子。结构**产生得太多、太粗**。

| 臂 | `A_L1` | 相对冻结基线 | 水平比 | 日方差比 | 逐事件峰/基比 |
|---|---|---|---|---|---|
| `B0`（冻结核） | 1.0400772083480145 | 1.00 | 1.0 | 1.0 | 1.0 |
| **`P-upper`** ⭐ | 0.7373725809958451 | **0.71** | **9.143688123572442** | **314.148477382949** | **0.7089594648141899** |
| `S-soil` | 0.97915517578687 | 0.94 | 4.085796633815022 | 28.812173831181497 | 0.9414254710398771 |
| `S-unsat` | 0.9752709506769071 | 0.94 | 4.110311235620086 | 28.758986722547682 | 0.9376909164522111 |
| `D-const` | 0.7860814113413213 | 0.76 | 7.615085085789727 | 201.48536477261823 | 0.7557914018612885 |

**怎么读这张表。** 如果失败形态是"路径结构不够灵敏"，会看到
水平不动、方差小、事件比 ~1。看到的是相反的东西：

* 平均浓度 `25.81672495274234` mg/L，是冻结基线 `2.8234476727379607` 的
  **`9.143688123572442` 倍**；
* 日方差 **`314.148477382949` 倍**；
* 而**逐事件的峰/基比掉到 `0.7089594648141899` 倍**。

方差比远大于水平比（`314.148477382949` 对 `9.143688123572442`），
说明高方差**不是**被水平抬起来的，两者是**同一件事的两面**：
库存被以水的周转率**逐日**抽干，于是每一天的输出都跟着当天的水走，
日间变异性爆炸，而"峰相对于基"这一比值反而**变平**——
因为**基也被抬起来了**。

去掉水平之后的 NSE 仍然是负的（`nse_level_removed` 主臂 `-227.34711143954794`），
所以这不是"只错在水平"。

**`D-const` 的读数**（把 $V$ 的时间变化删掉，只留饱和非线性）给出
`A_L1` = 0.7860814113413213、水平比 `7.615085085789727`、方差比 `201.48536477261823`。
它与时间变动的三个臂**同形**，说明**主因不是 $V$ 的时间结构**——
删掉时间变化并没有把形态改回来。

## 三、为什么是**恒等式**造成的，而不是巧合

P1 证伪器在**四个核臂上全部点火**：

| 臂 | `tau_eff` 中位 / `tau_hydro` 中位 |
|---|---|
| `P-upper` | **0.996355630760417** |
| `D-const` | 0.9945 |
| `S-soil` | 0.8552 |
| `S-unsat` | 0.8528 |

比值都落在 1 附近。**关键在于这不是数值巧合，是代数恒等式**：

在线性闭包 $g(x)=x$ 下，$M$ 池的逐日存活因子是

```
carry = (1 - g_u) · s_M
```

而

```
1 - g_u = 1 - Q_u/V_u = 1 - Q_u/(S_post + Q_u) = S_post/(S_post + Q_u) = S_post/V_u
```

**`S_post/V_u` 正是"留存下来的水占出流前水量的比例"**。于是

```
-ln(carry) = -ln(S_post/V_u) - ln(s_M)
```

`ln(s_M)` 的实测范围是 `[-0.0034, -0.00028]`（由 `s_M_range`
`[0.9966033069492995, 0.9997228863464569]` 给出），相对水的 O(1) 项**可以忽略**。

**所以：N 的记忆寿命在本核里就是上层水的滞留时间，而且是"由构造决定"的，
不是"由测量发现"的。** 独立复算把这条等式钉到了一 ulp 之内
（`max_abs_diff` = `2.220446049250313e-16`，`max_abs_diff_in_ulps` = `1.0`，
`holds_to_one_ulp` = `true`）。

**这条推论有两面，都必须说出来：**

* **它使本轮的事件门失败不可解释为机制失败。** 一个把"库存寿命"与"水的寿命"
  焊死的核，被水文学的时间尺度**完全支配**，它测不出陆相动员的时间结构。
* **它也使 P1 这条预注册预测本身失去信息量。** `N5` 原文记录了这一点：
  §2.7 把 "$tau_{\rm eff}\ll tau_{\rm hydro}$" 当作指向 $k_m$ 的指纹、
  把"只有事件后 fast/slow 恢复相位不对"当作指向 $k_{ex}$ 的指纹；
  在本核里**第一个指纹由构造必然成立**，所以它**不能用来区分**指向。

**这正是为什么结论走的是判决表的第 6 行，而不是第 7 行。**
第 7 行 `NO_AMPLITUDE_MECHANISM` 的条件（主臂 $A_{L1}$ 不高于冻结基线）**也满足**，
两行在一个臂的事件读数上**重叠**；预注册在**第 7 行自己的定义里**写明
"且不满足 `MOBILE_POOL_MAPPING_LIMITED` 的任一条件"，
所以第 6 行**先测**。这不是挑软的写——顺序在 `work/verdict_dp.py` 里写死，
而且判决是**纯函数**：读数 → 结局，不重跑任何模型。

承载该结局的**条件**是 §2.6 P1 这个**布尔量**（预注册的证伪器），
不是事后发明的阈值。两条旁证（月初脉冲占比、水平/方差解耦）**只并列报出、
不承载判决**——预注册里没有给"退化"注册任何数。

## 四、三条旁证

### 4.1 输出退化为月初脉冲（P3）

| 占比 | 值 |
|---|---|
| 月初日占天数 | 0.03285420944558522 |
| `F_f` 质量落在月初日 | 0.16954662019375846 |
| `A` 落在月初日 | 0.06585148807196758 |
| `E_u` 质量落在月初日 | 0.12356450707040552 |
| **`F_s` 质量落在月初日** | **0.03216374515683588** |

过表征 `5.001824614730297` 倍。**`A` 在很大程度上量的是日历而不是机制**，
按 P3 的规定照实写。

**但同时注意最后一行**：`F_s` 的占比 `0.03216374515683588`
与天数占比 `0.03285420944558522` **几乎相同**——脉冲**没有**以同样的强度穿到慢路。
这是"两条路不相等"的又一个独立读数，方向与 §1.2 一致。

### 4.2 水平与振幅**不可分离**（N6）

`N6_note` 原文：**"this round has NO level lever (unlike round 5, which had k_r),
so a level failure and an amplitude failure are NOT separable and neither may be read as
evidence about the other."**

本轮**没有**任何水平杠杆（不像 round 5 有 $k_r$）。
所以**不得**把水平缺口当成振幅的证据，也**不得**反过来。
`N6_level` 里 `P-upper` 的 `in_gate` = `false`，`ratio_to_frozen` = `9.143688123572442`；
`B0` 的 `in_gate` = `true`（它就是基线）。

### 4.3 慢路是定常线性水库——但**不得**读成"慢路不存在"

P2 的结果：`relative_bandwidth` = `0.06061447917680636`，
而反解参照是 `0.061`。**预测"明显大于 6.1%"被证伪**。

**但原因是代数，不是物理**：由 $V_s=S^{\rm post}+Q_s$ 与 $S^{\rm post}=Q_s(1-lr)/lr$ 得

$$x_s=\frac{Q_s}{S^{\rm post}+Q_s}=lr\quad\text{（精确）}.$$

⇒ "生产者直写存储"与"反解路"在 $x_s$ 上**是同一条路**，
带宽由构造相同。观测到的 `0.06061447917680636` 就是 `lr` 的带宽。

按预注册规定照实写：慢路是**定常线性水库**，
其振幅响应只能经 $L^{\rm pre}$ 与 $\varphi(x_s)$ 而来。**这不是"慢路不存在"。**

`N7` 的读数（`gs_min` = `0.007344138888149189`，`gs_max` = `0.007790193338694744`，
逐河段带内相对带宽中位 `0.05808263453759824`）与此一致：
**在线性闭包下，慢路释放分数逐河段是常数到 float64 精度**，
慢路**不携带自己的时间变化分数**。登记为**推论**，不是"不存在"。

## 六、这一轮**没有**看到的问题

必须点名三件**本轮无法回答**的事，防止结论被读大：

1. **"双路径移动水浓度结构行不行"——本轮答不了。**
   主因在"把全部 $A$ 当成 mobile N"这个**上界假设**上。
   按 §2.7 的注册规则，这一层要**单独判过**才能问路径结构。
2. **"水平能不能同时中性"——本轮答不了。** 没有水平杠杆（N6）。
   注意所有核臂的 `in_gate` 都是 `false`，包括"最好"的那一个。
3. **"慢路的振幅响应来自哪里"——本轮只给出了必要条件。**
   在 `g=x` 下慢路释放分数逐河段常数；它的问题被**并进了**可动性映射，
   因为 $L^{\rm pre}$ 本身由 $J=E_u(1-\phi_f)$ 灌入，而 $E_u=A g_u$ 正是被质疑的那一项。

## 七、不授权什么（§5 红线的现场复述）

* 不授权"关闭陆相结构"——`forbidden` 字段里逐字写着
  `"closing the land-phase structure, and jumping to an additional event source"`；
* 不授权跳到额外的附加事件源；
* 不授权把 `LEVEL_*` 与 `AMPLITUDE_*` 两方互为证据；
* 不授权把 `R5-ref` 的读数写进任何门的通过判定
  （`reference_arm_carries_no_gate` = `true`，它是**结构性**排除：一个门布尔量都不带）；
* 不授权事后放宽任何门、任何阈值、$\varepsilon_{\rm turn}$ = `0.05`；
* 不授权"因为本轮失败"而重启任一已关闭轴；
* **本轮零拟合**，所以**任何授权都只是"授权下一轮"**，不是机制被证实的证据。

## 八、把这一轮放进序列里

前四轮把"**什么时候浓**"这条轴试到了尽头（水文 → hazard → calendar → NH₄ 池 →
静态直接源 → event store → 事后路径分配 → 动员前路径特异浓度）。
本轮第一次换的是**结构**，不是乘子：把陆相动员从 $E=avp$ 换成
"一个上层移动水浓度 + 两个浓度储层 + 各自 $Q\times C$"。

**换结构没有带来振幅，但它带来了一个前四轮拿不到的结论**：
**在零参数、冻结水文学下，把全部 legacy 库存当作 mobile N 这条上界假设，
在事件尺度上是不可用的——它把输出变成逐日跟随水的映射，峰/基比反而被抹平。**

这是"已依次排除"清单上**新的一项**，也是下一轮方向的**唯一**依据。
