## 二、检查器自身的空洞性自检（D39）

### 2.1 为什么必须有这一项

前几轮的交付机检是**逐轮复制的**。`legacy-checker-copies-stay-vacuous` 这条教训说：
**一份逐轮的 `check_delivery.py` 副本会保留它当年的规则**，
所以**更早轮次写下的 `passed: true` 不构成证据**。
本轮的设计要求是：**检查器必须先自检再上岗，且自检读数落盘**（§9 硬闸门 ⑱）。

### 2.2 **五**枚人造探针与它们的读数

落盘于 **`reports/_check_delivery_selfcheck.json`**（`n_probes` = 5、`n_probes_passed` = 5）。
`what` 原文：**"Synthetic inputs only; no corpus file is read, so no reading here can pass by
accident of this round's data."** —— 探针**不读任何语料文件**。

| # | 探针 | 关键读数 | `ok` |
|---|---|---|---|
| 1 | 语料中的非有限值 | `floats_extracted` = `["1.2758737517831669", "inf"]`；`must_resolve` 解析成功；`0.987654321`/`12345.6789`/`3.14159265358979` **现在不解析**，而**在继承下来的 body 下三个都解析** | `true` |
| 2 | 带符号的负字面量 | 现在的切分是 `-0.1407034380572627`（解析成功）；继承下来的是 `0.1407034380572627`（**丢掉了负号**，解析失败） | `true` |
| 3 | 科学计数法的尾数 | `now_tokens_from_LIT_RE` = `[]`；继承下来的是尾数 `2.220446049250313`；`SCI_RE_tokens` = `["2.220446049250313e-16"]`（解析成功） | `true` |
| 4 | 路径检查的一半是活的 | 探针文件 `20260920_1\work\_selfcheck_probe.md` 写入后运行 `check_paths`，`n_ok` = 2，`missing` **恰好**是 `["reports/__no_such_file__.json"]`，然后**删除探针**（`probe_file_removed_after_use` = `true`） | `true` |
| 5 | **豁免是活的还是死的** | 用一个**假种子**换掉真种子后，原先被豁免的字面量**不再**被覆盖（`'0'*64` 时**一个都不覆盖**）；换回真种子则覆盖恢复 | `true` |

**探针 1 为什么重要**：语料里**只要有一个 `inf`**，
`abs(f - v) <= abs(f) * rel` 对**每一个有限 `v`** 都成立（两侧都是 `inf`），
于是整个字面量闸门**变成空洞**。继承下来的 body 对一个只含 `inf` 的语料
**对三个有限值全部返回 `True`**；修好后的 body **只对语料真正含有的那个值返回 `True`**。
**检查 (1) 在两个方向上都是活的。**

**探针 4 为什么重要**：它证明路径检查**不是**恒真——
一个不存在的路径被报为 `MISSING`，而不是被静默吸收。

**探针 5 为什么重要，以及它登记的是一条本轮**新增**的机制**：
本轮的台账（`已关闭假设台账.md`）是**承接 round 5 的复制件**，其中 137 条字面量
**逐字出现在摘要核验过的种子文件里**，因此按 `SEEDED_COPIES` 判为
`inherited`（豁免），不计 UNRESOLVED。**任何豁免都是放水的入口，所以它必须可撤销**：
`_seed_tokens_for` 在**种子摘要不符时返回空豁免**，探针 5 用真种子/假种子两次切换证明
**唯一的判定依据是种子的 sha256，不是"文件名叫台账"**。**本轮自己写的字面量一条也豁免不了**
（探针 5 同时断言这一点）。

**必须同时写明它豁免了什么、没有豁免什么**：豁免**只覆盖字面量**、
**只对一份具名文件**、**只在种子摘要逐位相符时生效**；
判据（`_near` 的容差、`LIT_RE`/`SCI_RE` 的形态、路径规则、五门阈值）**一条都没有被豁免触及**。
**并且**：`reports/_check_delivery_selfcheck.json` **刻意不进 CORPUS**——
它的全部内容就是"按构造不该解析成功"的合成哨兵，把它入册正好会毁掉探针 1 要证的那件事。

### 2.3 自检是**上岗的先决条件**，不是附注

`work/check_delivery.py` 的 `main` 在跑任何报告之前：

```python
selfchk = selfcheck()
(R / 'reports' / '_check_delivery_selfcheck.json').write_text(
    json.dumps(selfchk, indent=1, ensure_ascii=False, default=str), encoding='utf-8')
print('D39 SELF-CHECK  %d/%d probes passed  ->  %s' % (...))
if not selfchk['passed']:
    print('DELIVERY_CHECK_ABORTED: ...')
    return 2
```

即：**自检不过，检查器拒绝运行**（返回码 2），不会产出任何 `<报告名>_delivery_check.json`。
若某份报告没有对应的 `_delivery_check.json`，那本身就是读数。

### 2.4 自检对**本轮检查器**修掉的三处继承缺陷的登记（D39 (a)(b)(c)）

1. **(a) 空转**：继承下来的 body 在 `inf` 在场时对任意有限值都返回 `True`。
2. **(b) 两个方向的假阳性**：`(\d+\.\d{3,})` **不捕获负号**（而 `_near` 比的是**带符号**的语料值），
   所以每一份报告里的每一个负字面量都被报为未解析——
   `-0.1407034380572627` 是 `_corpus_numbers` 自己给出的 `median_station_nse` 基线值；
   同一个模式还把 `2.220446049250313e-16` 的**尾数**当成裸小数去查。
   继承下来的模式里，**闸门不只是空洞的，它在另一个方向也是错的**。
3. **(c) 覆盖面依赖文体**：路径模式原先要求反引号内是一个**完整**路径，
   于是用本谱系最常用的 `report.json::key` 记号写的引用**整体逃逸**——
   `专家诊断报告.md` 只被查到 8 条路径，而它引用了几十条。
   **一个覆盖面取决于行文风格的检查器不是检查器**，所以后缀现在被消费并丢弃。

### 2.5 冻结预注册的**显式排除**及其未解析引用数

`reports\预注册_判据与门槛.md` 是**冻结的预注册**，其 sha 已注册并在每个阶段前复核，
**改它——哪怕只是修一个引用——都会使本轮作废**。
它同时**早于**本轮检查器的根表，所以它的一些引用是裸的生产者文件名，没有任何已声明的根能解析它们。

两个诚实的选项是 (a) 加一些使裸名能解析的根（那会**削弱**检查 (2)），
或 (b) **跳过该文件并且说出来**。取了 (b)：

```
预注册_判据与门槛.md EXCLUDED (frozen pre-registration, sha verified)
  -- 3 unresolved citation(s) are NOT checked here:
     ['20260828_25_3\\scripts\\hydrology_core.py', 'hydrology_core.py', 'model.py']
```

**未解析引用数被打印出来，所以这个省略是可见的，不是被静默吸收的。**
三个里面第一个是**第三处既存引用缺陷**（见 `实际方法与偏离.md` §七）；
`phase0_gates.py:42-43,198-199` 已经把它登记为 `plan_cited_path_does_not_exist`
并要求了实际使用的路径。

## 三、邻居轮次未被改动（§9 硬闸门 ⑰）

落盘 **`reports/neighbour_write_check.json`**。

### 3.1 为什么这是一个模块而不是一行 `sha256sum`

`evidence-file-needs-a-producer` 这条教训：**只以 shell 命令形式存在过的比对无法重跑**，
而且读者**无法分辨**它打印的 sha 是不是它本该比的那些。
本模块是这次比对的**注册生产者**：它**两个前像都点名**、**都打印**、**把差异写盘**。

### 3.2 三个**互相独立**的前像

| 前像 | 内容 | 为什么它不是"看的时候磁盘上恰好是什么" |
|---|---|---|
| ① 本轮第 ⑤ 步留影 | `reports/audit_dp.json::neighbour_json_shas` 的 29 个 JSON 摘要 | 由 `work/audit_dp.py` 在**第 ⑤ 步**写下——**晚于第 1–4 步、早于第 ⑥ 步、早于任何报告存在**。仍然吻合的摘要 = 第 1–6 步与七份报告都没动过它 |

| ③ mtime 扫描 | 邻居 `reports/` 与 `work/` 下 mtime ≥ 本轮开始时刻的文件 | 阈值由**本轮自己最早的 `work/*.py`** 派生（`round_start_derived_from` = `probe_sources.py`，`round_start_epoch` = `1789838366.5993543`），**不是硬编码**，所以不会漂移；且**下界方向是安全方向**（只会多报，不会漏报） |
