# 模型与目标逐项说明 —— `20260920_1`

## 一、模型：守恒的双水路移动水浓度陆相灰箱

### 1.1 唯一的一条结构改动

**被替换掉的**（前四轮陆相动员的全部拼写）：

```
E  = av * prob        # 动员量：可用量 × 一个经 hazard 调制的概率
fast = E * f          # 快路
pre  = L + E*(1-f)    # 慢路
slow = pre * l
```

**换成的**（本轮，逐字）：

```
A      = max(M[r] + inp[t,r] - demand[t,r], 0.)        # 递推式逐字沿用
Qu     = Qf[t,r] + Qp[t,r]                              # mm/day，上层总出流
xu     = Qu / Vu[t,r]                                   # Vu = 出流前上层体积，mm
g_u    = g(xu)                                          # 全核唯一的 g
Eu     = A * g_u                                        # 上层总可移动 N，kg
phi_f  = Qf[t,r] / Qu                                   # 水量分水比例
F_f    = Eu * phi_f                                     # 快路
J      = Eu * (1 - phi_f)                               # 快 -> 慢
M[r]   = A * (1 - g_u) * s_M[r]                         # 与冻结核同拼写
Lpre   = L[r] + J
xs     = Qs[t,r] / Vs[t,r]
g_s    = g(xs)                                          # 同一个 g
F_s    = Lpre * g_s
L[r]   = Lpre - F_s
local  = F_f + F_s                                      # kg N/day per reach
```

### 1.2 六点必须同时成立（逐条，全部实测通过）

**(1) 同源性。** $F_f$ 与 $J$ 是**同一个 $C_u$** 乘两个水量。
$\phi_f$ 与 $1-\phi_f$ 是**分水比例**，不是两个浓度 ⇒ **不存在 fast/percolation 的先后**。
机器证据：`work/audit_dp.py` 的源码扫描断言 `(A - F_f)` **不出现在 $J$ 的构造里**
（`N9.named_free_choices` 中的 `"phi_f and percolation share one upper concentration"`）。

**(2) 守恒。** $F_f+J=E_u[\phi_f+(1-\phi_f)]$，逐项 $\le A$ ⇒ $M\ge0$；
$F_s<L^{\rm pre}$ ⇒ $L>0$。**有限库存、非负、无 cap、无 `min()`。**

**(3) $\phi_f$ 只能在两个出口之间分水，不能改总量。** 报告**不把 $\phi_f$ 的敏感性读成机制**。

**(4) $g$ 的唯一性。** 全核只有一个 $g$，上下层同用。取值集**闭合**：
只有 `x` 与 `-expm1(-x)` 两个成员，不得扩充。

**(5) 数值拼写（N12）。** $g$ 取指数形时**必须**写 `-np.expm1(-x)`，不得写 `1-exp(-x)`。
**实测的两个值**（`expm1_underflow_probe`）：

| 表达式 | $x = 1\times10^{-200}$ 处的值 |
|---|---|
| `1.0 - np.exp(-x)` | **精确的 `0.0`** |
| `-np.expm1(-x)` | **`1e-200`**（原样返回） |

`naive_is_exactly_zero` = `true`、`neg_expm1` = `1e-200`、`stable_equals_x` = `true`。
这是**断言**，不是风格约定。源码扫描（**AST 基**，不是文本匹配）在
`dp_kernel.py` / `closures_dp.py` / `common24.py` / `layers24.py` / `phase0_gates.py` /
`phase1_arms.py` 六个文件里找到 **0** 个表达式位置。

**(6) 归约点存在（N1）。** 注入 $g_u:=p_{\rm frozen}$、$\phi_f:=f_{\rm frozen}$、
$g_s:=l_{\rm frozen}$ 时，新核与冻结核**逐位相同**。见 §四。

### 1.3 浓度的稳定形（§1.2，**分母不含 $Q$**）

$$C_u=\frac{1000\,A}{(area\_ha\cdot10)\,V_u}\,\varphi(x_u),\qquad
C_s=\frac{1000\,L^{\rm pre}}{(area\_ha\cdot10)\,V_s}\,\varphi(x_s),\qquad
\varphi(x)=\frac{-\operatorname{expm1}(-x)}{x}\in(0,1].$$

* $\varphi\equiv1$ 对应 $g(x)=x$；$\varphi(x)=-\mathrm{expm1}(-x)/x$ 对应 $g(x)=1-e^{-x}$。
* **分母里没有 $Q$** ⇒ **underflow 与 NaN 同时消失**，$Q\to0$ 的极限自动给出。
  **不得**写 $C=1000F/Q$ 的直接相除。
* 两路不相等，是因为 $L^{\rm pre}\ne A$、$x_s\ne x_u$、$V_s\ne V_u$，
  **不是**因为手工乘了一个路径特异因子。**没有任何一处手工施加的路径特异因子。**
* 与 INCA-N 的对应：$C_u\to1000A/(area\_ha\cdot10\cdot V_u)$ 即其 $N/V$。

实测分布（`C_distribution`，mg/L，主臂 `P-upper`）：

| 量 | min | p1 | median | p99 | max |
|---|---|---|---|---|---|
| $C_u$ | 0.0 | 0.0 | 3.6968955930054976 | 218.65335814504965 | 1294.159026440647 |
| $C_s$ | 0.0 | 0.6472093406443111 | 6.338753367127263 | 57.86119453798692 | 331.3940062499699 |

**披露**：$C_u$ 的最大值落在深层尾部格（$V_u$ 触底到约 `2.6485864581430722e-204` mm）。
这是**分布读数，不进任何判据**——全部判据读的是站点-日的 `pL1/pL2/pL3`。

### 1.4 单位约定（登记，不猜）

* `Qf = fast_water/(area_ha*10)`、`Qp = percolation`、`Qs = slow_water/(area_ha*10)`，
  三者均 **mm/day**；$V$ 均 **mm** ⇒ $x=Q/V$ 单位 **1/day**，$g$ 无量纲，
  **面积在 $x$ 里整体约掉**。
* 浓度一律 **mg/L**，且**只用 §1.3 的稳定形**。硬闸门 ⑬ 由此满足。
* 参考期 **1961–2020**，评估期 **2021–2024**。

### P2 —— 慢路的时间常数。**被证伪，而且是被代数证伪的。**

预测：若 $V_s$ 取生产者直写状态，$\pi_s$ 的时间带宽**应明显大于** 6.1%。

实测（`P2`，四臂相同，`n` = 4544176）：

| 量 | 值 |
|---|---|
| `median` | 0.00735887623886793 |
| `relative_bandwidth` | **0.06061447917680636** |
| `inverted_route_bandwidth_reference` | 0.061 |
| `frac_xs_eq_1` | 0.0 |
| `frac_xs_ge_0p99` | 0.0 |

**为什么必然如此**：由 $V_s=S^{\rm post}+Q_s$ 与 $S^{\rm post}=Q_s(1-lr)/lr$ 可**解析地**得

$$x_s=\frac{Q_s}{S^{\rm post}+Q_s}=\frac{Q_s}{Q_s(1-lr)/lr+Q_s}=lr\quad\text{（精确）}.$$

⇒ **"生产者直写存储"与"反解"在 $x_s$ 上不是两条独立的路**，
它们的带宽**由构造相同**。观测到的 `0.06061447917680636` 就是 `lr` 的带宽，
与反解参照的 `0.061` 吻合**正是因为它就是同一个量**。

**这条必须写成"预测被代数证伪"，不得写成"慢路不存在"。**
按预注册要求照实写：慢路是**定常线性水库**，其振幅响应只能经 $L^{\rm pre}$ 与 $\varphi(x_s)$ 而来。
