## 一、这一轮问的是什么

把陆相动员从

```
E_t = av_t · p_t
```

换成**一个上层移动水浓度、两个浓度储层、各自 Q×C**：

```
A    = max(M[r] + inp[t,r] - demand[t,r], 0)      # 递推逐字沿用
Qu   = Qf + Qp          V_u = 上层储量(mm)         x_u = Qu / V_u
g_u  = g(x_u)           E_u = A · g_u
phi_f = Qf / Qu         F_f = E_u · phi_f         J = E_u · (1 - phi_f)
M[r] = A · (1 - g_u) · s_M[r]
Lpre = L[r] + J         x_s = Qs / V_s             g_s = g(x_s)
F_s  = Lpre · g_s       L[r] = Lpre - F_s          local = F_f + F_s
```

`g` 是**唯一**的非线性算子，且闭集只有 `{x, -expm1(-x)}` 两个取值；本轮由 Phase 0 的
**储量时序语义**选定为 **`x`**（见 §四.2）。不新增乘子、不新增 `k_r`、不引入 calendar /
hazard / source map，`k_ex = 0` 且 `k_m` **不出现**。

问的是：**在冻结水文学、冻结参数、零新参数下，它能不能在不抬长期平均水平的前提下产生事件振幅？**

## 二、答案：不能，而且失败的形态是**可命名**的

四个装新核的臂，事件比**全部低于**冻结基线，而水平与日方差**全部抬高**：

| 臂 | `A_L1` | 相对冻结基线 | 水平比 | 日方差比 |
|---|---|---|---|---|
| `B0`（冻结核，锚点） | `1.0400772083480145` | 1.00 | 1.00 | 1.00 |
| `P-upper` ⭐ 主臂 | 0.7373725809958451 | **0.71** | **9.14** | **314.15** |
| `S-soil` | 0.97915517578687 | 0.94 | 4.09 | 28.81 |
| `S-unsat` | 0.9752709506769071 | 0.94 | 4.11 | 28.76 |
| `D-const`（时间结构诊断臂） | 0.7860814113413213 | 0.76 | 7.62 | 201.49 |
| `R5-ref`（读盘参照，**不进任何门**） | 1.244023607865766 | 1.20 | 0.9945297890116693 | — |

主臂的平均浓度 `25.81672495274234` mg/L 是冻结基线 `2.8234476727379607` 的 9.14 倍，
日方差 314 倍，而**逐事件的峰/基比却掉到 0.71 倍**。这是"库存被以水的周转率直接抽空"的
签名，不是"路径浓度结构没能力"。

判决表里与它重叠的那一行 `NO_AMPLITUDE_MECHANISM` 的条件（主臂 `A_L1` 不高于冻结基线）
**也满足**；判决按预注册顺序**先测 `MOBILE_POOL_MAPPING_LIMITED`**，它命中，于是它出线。
这不是挑软的写，顺序是 `work/verdict_dp.py` 里写死的，且判决是**纯函数**：
读数 → 结局，不重跑任何模型。

## 三、为什么必然如此：P1 证伪器**在所有四个核臂上**点火

§2.6 的 P1 证伪器是"若 `tau_eff` 与 `tau_hydro` 同量级，则『M 是长期记忆』这句话在本核里不成立"。
实测：

| 臂 | `tau_eff` 中位 / `tau_hydro` 中位 |
|---|---|
| `P-upper` | 0.996355630760417 |
| `D-const` | 0.9945 |
| `S-soil` | 0.8552 |
| `S-unsat` | 0.8528 |

四个臂全部落在 1 附近，且**不是巧合，是恒等式**：线性闭包下

```
carry = (1 - g_u) · s_M,   而 1 - g_u = 1 - Qu/Vu = S_post/V_u  ← 这正是"留存水比例"
⇒ -ln(carry) = -ln(S_post/V_u) - ln(s_M)
```

`ln(s_M)` 只有千分之几（`s_M` 带内 `0.9966033069492995 – 0.9997228863464569`），
相对水的 O(1) 项可以忽略。**N 的记忆寿命在本核里就是上层水的滞留时间，而且是由构造决定的，
不是由测量决定的。** 所以主臂的事件门失败**不是**"双路径浓度结构无能力"的证据——
它标记 `UNIT_SCALE_LIMITED`，按 §2.6 P1 的规定照实写。

**结论**：不能把长期 legacy 库存直接等同于 mobile N。本轮**看不到**"双路径移动浓度机制行不行"
这个问题，直到把**可动性映射**这一层单独判过为止。

## 四、必须同时披露的四件事

### 1. 30 维里 **21 个失效**，而"零拟合"的意义与前四轮**不同类**

`h` 只经 `Predictor.hazard` 产生，新核不用 `h`；`f` 也被 `Q` 的物理分水取代。
在用的只有 `t[3]`（`log_tau_mineral_days`）与 `t[11..17]`（`gamma_lifetime_0..6`），
经 `s_M` 起作用，另有 `t[2]`（`v_f`，仅河道段）。**9 个在用 / 21 个失效。**

⇒ 本轮的零拟合**不是预算上的**，而是**结构上没有可拟合的东西**：陆相动员不含任何参数。
这比 round 5 的零拟合更强，也把它的证据面**收窄**——冻结参数包络对陆相已不构成约束。

### 2. `g` 取 `x`，而它**不是**预注册的安全默认

§3.3 的时序闸门给出确定答案：导出的状态是**出流后的 carry**，`S_pre` 可重建
（`max_rel` `3.573418689577043e-14`），且**全域 `x <= 1`**（`max_x` `0.9999999999999986`，
`n_x_gt_1` 0）。三条同时成立 ⇒ 按 §1.3 表**第一行**选 `g(x) = x`。
`is_the_registered_safe_default` 记录为 **false**——它是闸门的**确定性输出**，不是默认分支。

顺带推翻一个红队读数：**`pi` 的 16.45% 饱和完全是分母约定的产物**。
按**出流后**约定 `frac(pi >= 0.99)` = `0.17671124533908897`；
按正确的**出流前**约定 `frac(x >= 1)` = **精确的 0**，`frac(pi >= 0.99)` = **精确的 0**，
而且这是**代数上的必然**：`x <= 1` ⇒ `pi <= 1 - e^-1 = 0.6321`，`pi >= 0.99` 不可达。
两种约定之差 `DELTA_frac_pi_ge_0p99__pre_minus_post` = `-0.17671124533908897`。

### 3. 惰性守卫**保留**，而反对它的那条推导**是错的**

我原先的推导说"掩码上 `Q -> 0` ⇒ `E_u -> 0`，守卫可省"。**错的。**
实测：掩码上 `Q_u` 最大 `2.510e-14` mm/day，比冻结 `fast_water` 下界
`4.184469060922251e-200` 高**九个数量级**；同时上层储量塌到 `5.222e-28` mm。
于是 `x = Qu/(S_post+Qu)` 被推到 1：**掩码中位格上不加守卫的线性闭包给出 `g_u = 0.8637`**，
即**一天之内动员掉整个 legacy 库存的 86%**；`7.28%` 的掩码格落在 `x >= 0.99`。

冻结核在**恰好这些格**上给 `prob = 0`（掩码上 `fast_fraction` 最大值为 **0.0**），
所以守卫不是装饰——**它是 N1 归约检验能成立的唯一原因**。守卫保留，并登记为命名自由选择。

### 4. `V_s` 三路一致到 `6.952489252904095e-16`，但"三路"里有**恒等式**

`V_s` 取自生产者直写的 `lower_slow_storage_mm`（`20260828_38` 的哈希锁定 parquet），
反解路 `S_post = Qs·(1-lr)/lr` 与它最大相对差 `6.952489252904095e-16`。
**但要说清楚**：反解路复现的是 `S_post` 而不是 `V_s`（差一个 `l`，约 0.78%），
而且由 `V_s = S_post + Qs` 可解析得 `Qs/V_s ≡ lr` —— **反解路与直写路在 `x_s` 上不是独立的**。
这条恒等式是 P2 那条预注册预测**被证伪的原因**（见 `模型与目标逐项说明.md`），
不是"慢路不存在"的证据。

## 五、下一轮：唯一自由度是 `k_m`

§2.7 的注册规则：row 1（`tau_eff << tau_hydro`；输出退化为月初脉冲；所有物理臂都是
"库存被水周转率抽空"）指向 `k_m`；row 2（事件振幅已量到、只剩事件后恢复相位不对）指向 `k_ex`。
本轮落在 **row 1**：

* P1 证伪器在四个核臂全部点火；
* `F_f` 质量落在月初脉冲日的占比 `0.16954662019375846`，而月初日只占天数的
  `0.03285420944558522` —— 过表征 `5.001824614730297` 倍；
* 事件振幅**没有量到**（`A_L1` 0.71–0.94 倍），所以 row 2 的前提不成立。

⇒ **方向是 `k_m`；本轮不实现、不参数化、不预留开关。**

## 七、不授权什么

* 不授权"关闭陆相结构"；不授权"跳到额外的附加事件源"；
* 不授权把 `LEVEL_*` 与 `AMPLITUDE_*` 两方互为证据——本轮**没有任何水平杠杆**；
* 不授权把 `R5-ref` 的读数写进任何门的通过判定（它**没有任何门块**，这是结构性排除）；
* 不授权事后放宽任何门、任何阈值、`epsilon_turn`；
* 本轮**仍然零拟合**，任何授权都只是"授权下一轮"，不是机制被证实的证据。
