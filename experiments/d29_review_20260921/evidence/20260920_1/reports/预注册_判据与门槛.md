## 二、核（逐字，唯一拼写）

```
A      = max(M[r] + inp[t,r] - demand[t,r], 0.)
Qu     = Qf[t,r] + Qp[t,r]                      # mm/day
xu     = Qu / Vu[t,r]                           # Vu = 出流开始那一刻的上层储量
g_u    = g(xu)                                  # 唯一 g，本文件冻结为 g(x)=x
Eu     = A * g_u
phi_f  = Qf[t,r] / Qu
F_f    = Eu * phi_f
J      = Eu * (1 - phi_f)                       # 代码里不出现 (A - F_f)
M[r]   = A * (1 - g_u) * s_M[r]
Lpre   = L[r] + J
xs     = Qs[t,r] / Vs[t,r]
g_s    = g(xs)
F_s    = Lpre * g_s
L[r]   = Lpre - F_s
local  = F_f + F_s
```

**六点必须同时成立，缺一即 `BLOCKED`**：① 同源性（无先后，无 `A - F_f`）；② 守恒
（逐项 $\le A$，$M\ge0$，无 cap 无 `min()`）；③ $\phi_f$ 只分水不改总量；
④ 全核只有一个 $g$；⑤ 指数形必须写 `-np.expm1(-x)`；⑥ 归约点 N1 存在。

**稳定浓度形（分母不含 $Q$）**：
$C=\dfrac{1000\,X}{(area\_ha\cdot10)\,V}\varphi(x)$，$\varphi(x)=\dfrac{-\mathrm{expm1}(-x)}{x}$。
$g(x)=x$ 时 $\varphi\equiv1$，除法被跳过而不是求值。

### 4.6 两个寿命：P1 被证伪，且是**恒等式**证伪

| 估计量 | $\tau_{\rm eff}$（N 记忆寿命） | $\tau_{\rm hydro}$（水周转） | 比值 |
|---|---|---|---|
| 中位数 | `5.3921` d | `5.4118` d | **`0.99636`** |
| 几何均值 | `0.176564` d | `0.176584` d | `0.999883` |

**两个估计量都必须报**，因为几何均值被最小的 carry 主导。

**证伪器命中**。而原因是恒等式：线性闭包下
$$\text{carry}=(1-g_u)s_M,\qquad 1-g_u=1-\frac{Q_u}{V_u}=\frac{S^{\rm post}}{V_u}$$
**正是上层储量的"保留水比例"**。于是
$$-\ln(\text{carry})=-\ln(S^{\rm post}/V_u)-\ln s_M,$$
而 $\ln s_M\in[-0.0034,-0.00028]$，相对 $O(1)$ 的水项可忽略。
⇒ **N 记忆寿命由构造成等于上层水滞留时间**，不是测量出来的。

**$s_M$ 绝对尺度（照报）**：`s_M ∈ [0.9966033, 0.9997229]`，即寿命
`[296 d, 3636 d]`；但它对本核的寿命只贡献 0.3% 的 $\ln$ 扰动。

> **R2′ 二次更正。** R2′ 说"$s_M$ 是寿命主项，round 5 漏了它"。这句
> **对冻结核成立**（$1-p_{\rm frozen}\approx1$，故 $s_M$ 是唯一项），
> **对本核不成立**（$1-g_u\approx0.8$，水项主导）。$s_M$ 既非可忽略也非主导——
> **哪一个成立由闭包决定，而闭包正是本轮改动的东西。**

⇒ **按 S2.6 P1 的规定执行**：该臂标记 $\boxed{\texttt{UNIT\_SCALE\_LIMITED}}$，
并登记：**若事件门失败，那不是"双路径浓度结构无能力"的证据**，
而是"库存被以水的周转率抽干"这一时间尺度事实。

**绝对尺度比比值更重要**：N 记忆是**旬以内**的
（`p90 = 8.27 d`，`max = 9.01 d`，`p10 = 0.0304 d`）。
