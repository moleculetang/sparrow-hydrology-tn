## 01 本轮问的问题，以及问题为什么这样切

### 1.1 上一轮的窄结论与它**不胜任**的那一步

`20260919_3` 的窄结论成立：把同一批**已经动员出来**的 N 只在 fast/slow 之间重新分配，
不足以解释事件振幅。但用户裁定：**"窄结论可靠，机制族层面的关闭不可靠。"** 两条理由：

1. **层不对**：它只改了总动员**之后**的分配 $f$；
2. **区间不对**：$\gamma$ 被归一化到 $z$ 的 sd 单位，整个被测区间都落在"同比例富集"**之下**，
   超比例区**从未被直接测试**。

### 1.2 于是本轮切的是**没测过的那个结构层级**

前面每一个失败实验——水文日化、FCT8、calendar、NH₄ 快池、$R$-cap、快慢重分配——
**全都保留同一个框架**：

> **先生成一个统一的总 N 动员量，再输送。**

而 SWAT+ / HYPE / mHM-Nitrate **都不这样做**。真正没测过的是：

$$\boxed{\text{N 质量应在「动员」\emph{之前}\ 就具有不同的可达浓度，而不是在动员之后才分快慢路径。}}$$

用户的原话把这两件事分得很清：**"路径有不同 N 浓度"尚未真正测试；
本轮只测试了"同一 N 质量在路径间怎么分"。这两件事不是一回事。**

### 1.3 干预形式：**一处**修改，**一个**参数

$$\frac{C_{\rm fast}}{C_{\rm slow}}=\Big(\frac{W_{\rm eff}}{W_{\rm ref}}\Big)^{\beta},
\qquad
W=Q_f+Q_s=\texttt{fast\_water}+\texttt{percolation}\cdot\texttt{area\_ha}\cdot 10,
\qquad W_{\rm eff}=\max(W,\ 10^{-3})$$

```python
Lf = np.log(Qf); Ls = np.log(Qs)
L0 = np.logaddexp(Lf, Ls)
Lb = np.logaddexp(Lf + beta*u/2.0, Ls - beta*u/2.0)
Xi = np.exp(np.clip(Lb - L0, -700.0, 700.0))
Xi[~active] = 1.0
```

核里**只差一行**：`prob = -np.expm1(-min(risk*Xi[t,r], 700.))`（冻结是 `min(risk, 700.)`）。
`f`、M/L 更新式、源账本、水文、路由**一字不动**；**`Predictor.hazard` 不重绑**
（与上一轮相反，显式断言）。$\beta=0$ 与冻结核**逐位相同**。

## 07 判决

### 7.1 判决式

$$\boxed{\textbf{PRE\_REGISTRATION\_GAP}}$$

`verdict_is_pre_registered = false`，`qualifies = false`，
`refit_authorised = false`，`mechanism_family_closed = false`。
落盘 `reports\verdict.json`（sha256 `898382605b1d019ddc880c9391c7d7c9a0760a42337d8ab5218f106c51712387`）。

**为什么不是四条分支中的任何一条**：

| 分支 | 要求 | 本轮 |
|---|---|---|
| `QUALIFY` | 有一个可用点五门全过 | 假（`n_all_five_pass = 0`） |
| `L1_ONLY` | **不存在**同时过 G1+G2 的可用点 | 假（$+0.5$ 与 $+1$ 都过） |
| `SATURATION_BOUND` | 所有**可用**点都过不了 G1 | 假（$+0.5$ 过） |
| `INSUFFICIENT` | **任何**点（含极限）都过不了 G1 | 假（四个点过） |

计数：`n_grid_points = 19`、`n_usable = 17`、`n_usable_passing_G1 = 4`、
`n_usable_passing_G1_and_G2 = 4`、`n_usable_passing_all_five = 0`。

### 7.2 处置（逐条，不得含糊）

1. **不按"最接近"挑分支**；
2. **不放宽任何门**、**不改聚合**、**不事后给网格加点**；
3. 判决写作 `PRE_REGISTRATION_GAP`，并**显式标记它非预注册**；
4. **不签发 `QUALIFY`**、**不授权任何重新拟合**；
5. **机制族记为未关闭**；
6. §六 的**兜底选点规则**照用，但**只用来命名一个参考点**：
   $\beta = +0.5$、$g = $ `7.219050947528546`、
   $A_{L1} = $ `1.2289037922001007`、$A_{L3} = $ `1.1553373082531406`、
   闭合缺口 `0.800803018997674`。

**先例**：计划自己在 §三 登记过 `INSUFFICIENT_BUT_RESPONSIVE`——
"**登记标签，非门槛变更**"。本轮走的是同一条路。

### 7.3 三条**不得越界**的读法

1. **不得**把 `PRE_REGISTRATION_GAP` 读成 `QUALIFY`（它明确 `qualifies = false`）；
2. **不得**把"80.1% 缺口闭合"读成"机制被证实"——
   它**没有**过 G4，且月尺度在崩（§5.3）；
3. **不得**把本轮的结局读成"路由压平已被解释"——
   §03 只说明它**不构成障碍**，没有解释它。

### 7.4 行动行（**收窄后的原句，逐字**）

$$\boxed{\text{不要再在「先造一个统一总动员量、再在路径间分配」这一套结构里改}}$$
