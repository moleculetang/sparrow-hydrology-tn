## 一、计划期就该知道、跑出来才知道的（**红队裁决的落地**）

### D1 指数 clip 从未触发（**计划把它当成结构性保证，实测它不触发**）

计划 §1.2/§九-3 说 `clip(±700)` 使 $\Xi\in[9.86\times10^{-305},1.014\times10^{304}]$，
"恒有限且恒正"，从而 $0\cdot\Xi=0$ 精确。**实测：该 clip 在 19 个网格点上一个都没触发**
（`reports\frozen_anchors.json::deviations.exponent_clip`）。

⇒ 不改代码，但**读法要改**：真正封住 `prob` 的是**乘积级封顶** `min(risk*Xi, 700)`；
指数 clip 的作用**只是**保证 `Xi` 有限正、从而 `0*Xi == 0.0` 精确。
把"clip 保住了数值范围"读成"clip 在起作用"是错的。

### D2 `~active` 与 `h == 0` **不是同一个掩码**（计划把两者当成同一件事）

计划 §1.2 论证"非活跃格上 `Xi` 被钉成 1 **不是干预**"，依据是
`fast_fraction == 0 ⟺ W < 1e-6 ⟺ h == 0` 三者重合。

**实测**：`h == 0 ⟺ W < 1e-6` **精确成立**（双向，零例外）；
但代码里注册的活跃掩码是 `active = W > W_FLOOR`（`W_FLOOR = 1e-3`），
两者在 **`1e-6 < W <= 1e-3` 这条带**上**不同**——
实测差 **5 格**（占全部 `9.3e-07`）。这 5 格上 `h != 0` 而 `Xi` 被钉成 1，
所以**钉住的确实是一次（极小的）真干预**。

* **处置**：**没有**去重写那条"不是干预"的强断言（它已被本轮的 Phase 0 证伪），
  改而断言**精确为真**的三条：`h_zero_iff_W_lt_1e_6`、`n_active_and_h_zero == 0`、
  `pin_is_within_the_band`；并把足迹作为 `D_pin_mask` 登记
  （`reports\frozen_anchors.json::deviations.D_pin_mask`）。
  实测上界：被钉格上 `max h = 0.000473712904325966`、`max W = 0.0007382603259854497`。
* **教训**：**一个已被自己的装置证伪的断言，不得因为"计划里是这么写的"而保留。**
  Phase 0 先失败了一次，改断言的是**断言**，不是**产物**。

## 四、判决面的偏离（**本轮最重要的两条**）

### D6 **预注册表里没有本轮结局对应的分支**（真实的预注册缺口）

计划 §六的表有四条判别分支：`QUALIFY` / `L1_ONLY` / `SATURATION_BOUND` / `INSUFFICIENT`。
**每一条的判别都只挂在 G1 或 G2 上**——因为 round 3 时真正的问题是"L1 到底能不能响应"。

本轮 L1 响应了，于是结局落在这张表**没有定义**的格子里：

> **存在一个可用的 $\beta$，G1 与 G2 同时通过，且在该点上 G3 与 G5 也通过，只有 G4 不通过。**

* `QUALIFY` 要求五门全过 ⇒ 不成立；
* `L1_ONLY` 要求"不存在同时过 G1 与 G2 的**可用** $\beta$" ⇒ 假；
* `SATURATION_BOUND` 要求"所有可用 $\beta$ 都过不了 G1" ⇒ 假；
* `INSUFFICIENT` 要求"**任何** $\beta$（含极限情形）都过不了 G1" ⇒ 假。

**处置（逐条，不得含糊）**：

1. **不按"最接近"挑分支**；
2. **不放宽任何门**；**不改聚合**；**不事后加点**；
3. 判决写作 `PRE_REGISTRATION_GAP`，并显式标记 `verdict_is_pre_registered = false`；
4. **不签发 `QUALIFY`**；**不授权任何重新拟合**（`refit_authorised = false`）；
5. **机制族记为未关闭**（`mechanism_family_closed = false`）——它清了五门中的四门；
6. §六 的**兜底选点规则**（"若无满足全部者，取满足 G1+G2 的最小 $|\beta|$"）
   **照用**，但只用来**命名一个参考点**，不构成授权：
   $\beta = +0.5$、$g = $ `7.219050947528546`、$A_{L1} = $ `1.2289037922001007`，
   闭合缺口 `0.800803018997674`（即 **80.1%**，远过 50% 那道坎）。

**先例**：计划自己在 §三 登记过 `INSUFFICIENT_BUT_RESPONSIVE`——
"**登记标签，非门槛变更**"。本轮走的是同一条路。

### D7 **G5 是单侧的，察觉不到崩塌——`G5_pass = True` 不得被读成"月尺度没问题"**

G5 逐字承自 `20260919_2\work\phase1_score.py:203`：

**这是单侧的**：它只在候选**比基线好出 0.005 以上**时拦住。

### D13 G4 用**非严格** `<=`（**承自 2 轮，不是本轮新选**）

G4 的判据是"F1／F3 距离**不增**"，本轮实现为 `D_cand <= D_base`（**非严格**）。

* **它不是本轮新选的口径，是承下来的**：`20260919_2\work\phase1_score.py:213-214`
  就是 `j2_holds = D_beta_cand <= D_beta_P`、`j3_holds = D_alpha_cand <= D_alpha_P`。
  本轮的 `work\phase2_full.py` 逐字沿用。
* **但同一族的判据在 `20260919_1` 里是严格 `<`**：该轮 `work\phase1_fingerprints.py:569-576`
  的 `dist_table` 把候选臂记作 `U`、基线臂记作 `P`，判据是
  `D_U_lt_D_P = bool(np.isfinite(dU) and np.isfinite(dP) and dU < dP)`（**严格**），
  并被 J3／J4 用作 `holds_literal` / `holds_strict`。
  ⇒ **准确的陈述是：本轮沿用的是 `20260919_2` 的非严格口径，而 `20260919_1` 的同类判据是严格的。**
* **这一条写错过两次，两次都登记在这里，因为第二次比第一次更危险**：
  第一版写"与 `20260919_1` 的严格 `<` 不同"——**实质上是对的**，只是没给出行号；
  随后被"更正"成"**先核过 `20260919_1` 没有对应的距离准则**"——**实测为假**，
  准则就在 `phase1_fingerprints.py:576`（它当时按 `D_cand`／`D_base` 这两个
  **本轮与 2 轮的变量名**去搜，而 1 轮叫 `D_U`／`D_P`，于是搜不到并据此下了结论）。
  ⇒ **一个自称"先核过"的否定断言，其可信度取决于搜的是什么名字**；
  把一条**真**陈述换成一条**假**陈述，是这种搜索失败的标准后果。
  现在这一版是逐行读过 `dist_table` 之后落的。
* **为什么非严格是对的**：`D_cand == D_base` 意味着**这个装置没有动 F1／F3 那两根轴**，
  而不是"动坏了"。取严格 `<` 会把"完全没碰"判成失败，方向是错的。
* **代价与实测**：非严格使 G4 **略微更松**。实测上这一松没有救任何人——
  唯一进到 G4 的候选点 $\beta=+0.5$ 是 `D_alpha_cand = ` `0.0249393727386844` $>$
  `D_alpha_base = ` `0.0200611184995979`，**严格与不严格都不过**。
