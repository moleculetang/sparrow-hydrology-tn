## 2. 被检验的命题

$$\boxed{\text{让"快速水真正携带自己的 N 浓度"——即在总动员量形成\emph{之前}\ 就存在路径特异浓度——能不能造出缺失的事件振幅？}}$$

冻结核是 `closures.py:14-29` 的 `scan`，其 `E = av·p` 里的 $p$ 只由**总** hazard 决定。
本轮**只**在 `E` 这一层加一个因子 $\Xi$，**不改** `f`、**不改** M/L、**不改**源账本、
**不改**水文与路由。核心区别是：

> **快速水携带自己的 N 浓度，而不是拿总动员量 N 的一个比例。**

## 3. 装置（`Xi` 的构造，拼写冻结）

$$Q_f=\texttt{fast\_water},\quad Q_s=\texttt{percolation}\cdot\texttt{area\_ha}\cdot10,\quad W=Q_f+Q_s$$

$$W_{\rm eff}=\max(W,\ 10^{-3}),\qquad
\mathrm{clim}_r=\overline{\log W_{\rm eff}[\cdot,r]}_{\ 1961\text{–}2020,\ \text{仅活跃格}},\qquad
u=\log W_{\rm eff}-\mathrm{clim}_r$$

```python
Lf = np.log(Qf); Ls = np.log(Qs)
L0 = np.logaddexp(Lf, Ls)
Lb = np.logaddexp(Lf + beta*u/2.0, Ls - beta*u/2.0)
Xi = np.exp(np.clip(Lb - L0, -700.0, 700.0))
Xi[~active] = 1.0
```

* `active = W > W_FLOOR`（`W_FLOOR = 1e-3`）。
* **clip 的是指数，不是 $\Xi$**；乘积级封顶 `min(risk*Xi, 700)` 原样保留。
* **拼写冻结**：$\beta=0$ 时 $\Xi$ 恒为 `1.0` 且**逐位**成立；`W*(1/W)` 这类
  "等价改写"会摧毁它。
* `Xi` 必须是 numba 函数的**实参**，不能是模块全局。

**三处入口**：六个模块的 `Transport`（`owner.Xi`）、`closures.scan`
（`CONFIG['Xi']`）、`cm.tag_scan` 与 `tagged_transport.tag_scan`（`CONFIG['Xi_tag']`）。

## 4. 参数化与**饱和普查**（先注册的机械可用性界）

$$\frac{C_{\rm fast}}{C_{\rm slow}}=\Big(\frac{W_{\rm eff}}{W_{\rm ref}}\Big)^{\beta}$$

| $\beta$ | 读法 |
|---|---|
| $0$ | 常数对比（= 冻结核） |
| $0<\lvert\beta\rvert<1$ | 次比例 |
| $\lvert\beta\rvert=1$ | 同比例 |
| $\lvert\beta\rvert>1$ | **超比例富集／稀释**（round 3 从未到达） |

**双拼写并列**：$g=\beta\cdot S_u$，$S_u = 14.438101895057091$。设计参数化取**原始 $\beta$**，
$g$ 只作并列列，**不进任何判据**。

**预注册可用性界（机械规则，非判断，不得事后放宽）**：一个 $\beta$ 只有同时满足

$$\mathrm{frac}(prob\ge0.99)\le 0.10\quad\text{且}\quad\mathrm{frac}(\lvert\Xi-1\rvert>10^{-6})\ge 10^{-3}$$

才**有资格**承载 `QUALIFY` / `L1_ONLY`；否则自动归入"极限情形"。

**同号并列时取负号**。**必须报出全部 19 个 $\beta$ 的完整读数**。

**判决层红线**：不得用"换判据／换聚合／换噪声带／换簇方案"把 `INSUFFICIENT` 读成 `QUALIFY`；
**不得把 §4 的可用性界事后放宽**；**不得把任何结局的动作用语写得比 §8 更宽**。
