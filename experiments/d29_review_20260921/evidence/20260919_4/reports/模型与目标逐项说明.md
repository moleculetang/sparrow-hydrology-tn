## 01 本轮不是一个拟合轮

### 01.1 被检验的命题

$$\boxed{\text{让「快速水真正携带自己的 N 浓度」——即在总动员量形成\emph{之前}\ 就存在路径特异浓度——能不能造出缺失的事件振幅？}}$$

零拟合是硬登记：**`n_fits = 0`，`fit_worker` 调用数 `= 0`**。四份产物各自登记一次
（`reports\phase1_l1.json`、`reports\phase2_full.json`、`reports\verdict.json`、`reports\audit_beta.json`）。
本轮不建模型、不调参、不重拟合、不引入任何新源。

### 01.2 冻结核与 `scan_mc`：逐行相同，只差一行

冻结核是 `20260916_2\vendor\research\closures.py` 的 `scan`，其陆相动员是 `E = av·p`，而 `p` **只由总 hazard** `h[t,r]` 决定：

```python
prod = risk                       # 冻结核
prob = -np.expm1(-min(prod, 700.))
```

本轮写在 `work\closures_mc.py::scan_mc` 里的那一份，与之**逐行相同，只有一行不同**：

```python
prod = risk * Xi[t, r]            # 本轮：只在 E 层乘一个因子
prob = -np.expm1(-min(prod, 700.))
```

标签支 `work\closures_mc.py::tag_scan_mc` 同样只改这一行：
`p = -np.expm1(-min(h[t, r] * Xi[t, r], 700.))`。

β = 0 时与冻结核 **`np.array_equal` 逐位**相等，4 路与 7 路同时成立、且逐通道成立
（`reports\frozen_anchors.json::no_op`：`scan_4way_array_equal = true`、`tag_scan_7way_array_equal = true`、
`TransportMC_apply_array_equal = true`、`beta0_Xi_max_abs_dev = 0.0`）。
乘积级封顶 `min(risk*Xi, 700)` **原样保留**，它是真正夹住 `prob` 的那一层（`product_cap_is_structural = true`）。

### 01.3 β 乘的是什么

$$\frac{C_{\rm fast}}{C_{\rm slow}}=\Big(\frac{W_{\rm eff}}{W_{\rm ref}}\Big)^{\beta}$$

β 是**原始的 log-log 弹性** `d log(C_fast/C_slow) / d log W`，**无量纲**。它乘的是**动员前的路径浓度对比**，
不是总 hazard 的水平。读法（`reports\预注册_判据与门槛.md` §4）：

| β | 读法 |
|---|---|
| $0$ | 常数对比（= 冻结核，逐位） |
| $0<\lvert\beta\rvert<1$ | 次比例 |
| $\lvert\beta\rvert=1$ | 同比例 |
| $\lvert\beta\rvert>1$ | **超比例富集／稀释** |

### 01.4 双拼写 `g`

`g = β · S_u`，`S_u = 14.438101895057091`。`g` 与 β **并列报出**，`S_u` 只作并列列、
**不进任何判据**（`reports\verdict.json::s_u_role`）。独立复算得到同一个 `S_u`
（`reports\audit_beta.json::own_S_u` 与 `own_S_u_matches_registered = true`）。
设计参数化**始终取原始 β**。

## 02 Ξ：装置本体

### 02.1 几何

$$Q_f=\texttt{fast\_water},\qquad Q_s=\texttt{percolation}\cdot\texttt{area\_ha}\cdot 10,\qquad W=Q_f+Q_s$$

$$W_{\rm eff}=\max(W,\ \texttt{W\_FLOOR}),\qquad
\mathrm{clim}_r=\overline{\log W_{\rm eff}[\cdot,r]}_{\ 1961\text{–}2020,\ \text{仅活跃格}},\qquad
u=\log W_{\rm eff}-\mathrm{clim}_r$$

参考窗严格早于评估期：`ref_years = [1961, 2020]`、`n_ref_days = 21915`、网格 `shape = [23376, 230]`、
`n_reaches = 230`（`reports\frozen_anchors.json::geometry`）。
`active = W > W_FLOOR`，`W_FLOOR = 0.001`（`work\xi.py`；`work\common22.py` 从 `xi.W_FLOOR` 转出）。
实测 `frac_active = 0.8452247567181501`，`frac_w_lt_1e_6 = 0.15477431330535965`。
两端极值：`w_min = 1.1123379224548185e-199`、`w_max = 369427579.3079815`、
`qf_min = 4.184469060922251e-200`、`qs_min = 6.938910163625934e-200`。

### 02.2 拼写冻结

```python
Lf = np.log(Qf); Ls = np.log(Qs)
L0 = np.logaddexp(Lf, Ls)
Lb = np.logaddexp(Lf + beta*u/2.0, Ls - beta*u/2.0)
Xi = np.exp(np.clip(Lb - L0, -700.0, 700.0))
Xi[~active] = 1.0
```

三条必须与读数一起看的性质：

1. **clip 的是指数，不是 Ξ**。实测 `exponent_clip_engaged_on_any_point = false`——19 个格点上一个都没触发；
   它保证的是 Ξ 恒**有限且严格为正**，从而 `0*Xi == 0.0` **精确**成立，pin 才不是一次干预。
2. **拼写是冻结的**：β = 0 时 Ξ 逐位全为 `1.0`（`beta0_Xi_is_exactly_one = true`）。
   `W*(1/W)` 之类的"等价改写"会摧毁逐位成立——这是**拼写**的性质，不是数学的性质。
3. **所有 19 点的 Ξ 都有限、都严格为正**：`all_betas_finite_and_positive = true`，逐点
   `finite/positive = true`、`n_nonfinite = 0`、`n_nonpositive = 0`（`reports\frozen_anchors.json::no_op`）。

### 02.3 Ξ 必须是 numba 的**实参**，不是模块全局

numba 的模块全局在编译期被冻结为常量，所以 Ξ 只能走两条路：

| 入口 | 载体 |

每个 Python 包装内断言 `Xi.shape == h.shape`（`work\closures_mc.py::_check`）：形状不符抛
`XI_SHAPE_MISMATCH`、两个来源不一致抛 `XI_SOURCES_DISAGREE`、未安装抛 `XI_NOT_INSTALLED`；

（numba 不做跨实参形状检查）。`pilot_indices = [157, 224]`，**0-based 列、从模型读、不硬编码**
（`reports\frozen_anchors.json::s2_1_single_source::install::pilot_indices`），
`Xi_shape = [23376, 230]`、`Xi_tag_shape = [23376, 2]`，且
`np_array_equal_tag_vs_slice = true`（标签切片就是 Ξ 的切片，按构造）。

## 03 三层、量纲、与"判据全在浓度上"

### 03.1 三层定义

| 层 | 组成 | 含义 |
|---|---|---|
| `L1` | `fast + slow + human_mass` | 陆相本地（快水 + 慢水 + 人类质量） |
| `L2` | `inlet + local` | 上游入口 + 本地 |
| `L3` | `boundary_mass` | 边界（输移/路由后） |

`work\layers22.py::forward_layers` 依次算 `local = fast + slow + model.human_mass(t)`、
`(inlet, official, releases) = SM.RiverN.apply(...)`、`mass = SM.boundary_mass(...)`，
再组装 `L1_kg` / `L2_kg` / `L3_kg`。`work\layers22.py` 与 `20260919_3\work\layers21.py`
**不是逐字节副本**：`diff -u` 退出码 **1**，两侧 `sha256sum` **不同**
（只读侧 `20260919_3\work\layers21.py` = `95daccdb9f812f540e48c8497ed25dbd43c4773499c56a4455bd6785d61d85b9`；
本轮的 `work\layers22.py` 侧**不在此处引用其 sha256 与行数**——该文件自身承载这段说明，
引用它就会写下一条**自指即失效**的数，且它在 12:24:26 仍在被编辑）；
差异**全部落在 docstring**，唯一的**可执行**差异是第 40 行的 `import common22 as C`
（原 `common21`），函数体逐行相同。见 `reports\实际方法与偏离.md` D17。

### 03.2 量纲：三层都归到浓度

$$pL^{*}=1000\cdot\frac{kg}{\texttt{water\_m3\_day}}$$

`pL1` / `pL2` / `pL3` 都是 **mg/L 浓度**。全层断言无质量列（`E.assert_no_mass_columns`）：
日尺度表只允许 `station_key` / `date` / `p` / `water_m3_day` 四列，列名不得含 `mass`、`load`、`kg`。

⇒ **所有判据都落在浓度尺度上**。本报告不含任何负荷量，也不使用负荷。

### 03.3 事件振幅 `A` 是一个浓度比

$$A_{L\ell}=\mathrm{median}_{e}\ \frac{c_{\rm peak}^{(e)}}{c_{\rm base}^{(e)}}$$

事件窗取自 `20260919_2\work\eventlib.py:148-153`（`TN_PRE_DAYS = 7`）：

| 窗 | 区间 | 端点 |
|---|---|---|
| base | `[t_start − 7d, t_start)` | **半开** |
| peak | `[t_start, t_end + 1d]` | **两端闭合** |

`c_base` 取基窗**中位数**，`c_peak` 取峰窗**最大值**；`A` 只对**有限事件**取中位数。
硬断言：`n_base == 7`、`n_peak == (t_end − t_start).days + 2`（峰窗恰好比事件窗长一天）。

事件集：**214** 个事件 / **15** 个站。
合格掩码 sha `872280128ed6261ca936544379d54e63800497e0ee66625bf1cf5b83c310af41`，
`n_rows = n_station_days = 12152`、`n_distinct_days = 871`、`n_stations = 15`。
**15 站全部进入，不做任何表现性站点剔除。**

### 03.4 判据面 vs 只报不门控

`j5_holds`（`mean_concentration_relative_change ≤ 0.005`）**同报不门控**：G1/G2 要求事件振幅大改，
j5 要求均值浓度改动小于 0.5%，两者**按构造对拉**；门控它会让本轮不可通过
（`reports\phase2_full.json::phase2_decision::tension_note`）。四个候选的
`mean_concentration_relative_change` 分别是 `0.22381499501517088`、`1.6856283205667486`、
`2.3356038582259484`、`7.336914087727148`，`j5_holds` 全为 `false`，**且四个并列报出**。

## 06 预注册可用性界（机械规则，**不得事后放宽**）

一个 β 只有**同时**满足下面两条，才**有资格**承载 `QUALIFY` / `L1_ONLY`：

$$\mathrm{frac}(prob\ge 0.99)\le 0.10\qquad\text{且}\qquad \mathrm{frac}(\lvert\Xi-1\rvert>10^{-6})\ge 0.001$$

常量：`SAT_BOUND = 0.10`、`DEGEN_FLOOR = 0.001`（`work\common22.py`；规则本体见
`reports\预注册_判据与门槛.md` §4）。这是**先注册的机械规则**，不是判断，也**不因结果放宽**
（`reports\frozen_anchors.json::saturation_summary::note`）。

实测：`n_admissible = 17` / `n_points = 19`——被剔除的是 **β = 0** 与 **β = +8**：

* **β = 0**：Ξ 逐位恒为 `1.0`，`frac_abs_xi_minus_1_gt_1e6 = 0.0` ⇒ 按构造退化
  （`beta0_degenerate_by_design = true`、`beta0_admissible = false`），
  这正是 β = 0 作为**基线**、不承载任何裁决的原因。
* **β = +8**：`frac_prob_ge_0p99 = 0.10885040026188138` > `0.10` ⇒ **饱和**
  （`not_saturated = false`）。它**仍然过 G1**（$A_{L1} = $ `1.2134646576106443`），
  但**不可用**，所以**不计入** `n_usable_passing_G1`——`admissible_betas` 不含 `0` 与 `8.0`。

对照：选定点 β = +0.5 的 `frac_prob_ge_0p99 = 0.0003305136446150641`，基线是
`0.00021091866797607356` 的同一量级；而 `-4.0` 点已经出现
`frac_prod_ge_700 = 2.938725709014076e-05`（乘积级封顶开始介入）。
被剔除的 `+8` 点 `frac_prod_ge_700 = 0.042320068148677205`，`xi_max = 3.4781516904461583e+37`
（`reports\frozen_anchors.json::no_op::per_beta_finite_and_positive`）。
