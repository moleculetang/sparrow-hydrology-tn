## 一、本轮要回答的**唯一**问题

> **只增加一个"legacy N → mobile N"的状态和一个转移率 `k_m`，
> 在冻结水文、冻结 `s_M`、零新参数、零拟合下，
> 能不能在同一个 `τ_m` 上同时买到事件振幅、且不把长期平均水平推出冻结基线？**

派生第二问（**决定结果的可解释性**）：

> **水平统计量到底是"通量型"还是"比值均值／水量加权型"？
> 这决定 `k_m` 能不能动水平，以及在哪一段 `τ_m` 上动。**

问题来源不是猜想，而是三条**零前向**可得的量化依据（见 §四）。

## 二、两池核（逐字，唯一拼写）

保留下来的：source ledger、crop demand、水文学、河道路由、观测算子、
**冻结的 `s_M`**、`g` 的两种拼写 `{x, -expm1(-x)}`、`φ`、`V_u = upper_water + Qu`、
`V_s = lower_slow_storage_mm + Qs`。
**替换掉的**：上一轮的单一陆相状态 `A` → 本轮的两个陆相状态 `N^L`（legacy，弱可动）与
`N^M`（mobile 可达）。慢层 `L` 与上一轮**逐字相同**。

```
NL   = N^L[r] + inp[t,r]          # 输入入口只在 LEGACY 侧
NM   = N^M[r]
P    = NL + NM
U    = min(demand[t,r], P)         # demand 从两池按比例抽，参数-free
U_L  = U * (NL / P) if P > 0 else 0.0
U_M  = U - U_L
nL   = NL - U_L                    # 抽完 demand 之后的 legacy
nM   = NM - U_M

T    = q_m * nL                    # ← 唯一的新机制：legacy → mobile 的一阶转移
str  = nL - T                      # N^{L,*}
pre  = nM + T                      # N^{M,pre}

Qu    = Qf[t,r] + Qp[t,r]
g_u   = g(Qu / Vu[t,r]) * guard[t,r]
E_M   = pre * g_u
phi_f = Qf[t,r] / Qu
F_f   = E_M * phi_f
J     = E_M * (1 - phi_f)
rem   = pre - E_M                  # N^{M,rem}
N^L[r] = s_M[r] * str
N^M[r] = s_M[r] * rem
Loss[t,r] = (1 - s_M[r]) * (str + rem)

Lpre = L[r] + J                    # 慢层与上一轮逐字相同
g_s  = g(Qs[t,r] / Vs[t,r])
F_s  = Lpre * g_s
L[r] = Lpre - F_s
local = F_f + F_s + human_mass(t)
```

`q_m` 一律写 `-np.expm1(-k_m)`。这不是风格约定，是**断言**：

（一个给 `1e-200`，一个给 `0.0`）。本轮把它**同时套在 `q_m` 上**。

## 三、本轮的**唯一自由度**：`τ_m` 一个标量

* `V_u`／`V_s`／`g`／`s_M`／水文学／30 维参数**全部沿用冻结值，一字不改**。
* `q_m = -expm1(-1/τ_m)`，`τ_m` 严格单调对应 `q_m`。
* **`k_ex = 0`，且 `k_ex` 不出现在任何方程里**；本轮**不实现、不参数化、不预留** `k_ex`。
* **`k_m` 不得写成 `T^mob = f(Q)·N^L`**：一旦让它依赖 `Q`，就等于把上一轮的恒等式装回来。

### 3.1 主臂的盲规则（**先于任何前向注册，绝不用性能挑**）

```

            = sqrt( 5.411787491476153   ×   6934.7280 )
            ≈ 193.724739 d   →   取最近的对数网格点   200.0 d
```

* 两个输入都是**冻结的、已量到并已登记的**数：
  `τ_water = 5.411787491476153 d`（上一轮 N5 的水周转中位）、

* 选它的理由**不看任何性能**：它是本轮所问区间的**对数中点**——

  也就是"什么 N 能碰到水"这一问的自然中心。

## 四、动机：三条**量化**依据（全部零前向可得）

### （A）两个动员率相差 `1169.7540716542715` 倍

| 量 | 值 | 来源（只读） |
|---|---|---|
| 冻结动员率 `prob` 中位（活跃、非事件日） | `1.442017619452899e-04 /d` | 上一轮 `phase0_amplitude_budget.json::elasticity/prob/outside/median` |
| ⇒ 冻结隐含 N 寿命 | ≈ `6934 d` ≈ 19 yr | 上式的倒数 |
| 新核 `g_u = Qu/Vu` 中位（活跃格） | `0.1687143749219422 /d` | 本轮 `phase0_gates.json::3.3_pi_census/pre__V=S_post+Qu.p50` |
| ⇒ `τ_hydro` 中位 / `τ_eff` 中位 | `5.411787491476153` / `5.392064939611057` d | `phase0_gates.json::N5` |
| `s_M` 实测带 / 隐含寿命带 | `[0.9966033069492995, 0.9997228863464569]` / `[293.90371030790203, 3608.1276544444436] d` | `phase0_gates.json::N5` |

⇒ **冻结模型把 N 关在寿命约 19 年的库里，新核把它放在寿命 5.9 天的库里。
`k_m` 就是横跨这 `1169.7540716542715` 倍的那一个旋钮**，而且它落在 `{τ_water, τ_frozen}` 之间时，
**不改水文、不加参数、不碰 30 维**。
（对应的**寿命**之比是 `1281.4117400574044`；两个比值是**两个不同的对象**，各报各的名字，
不混用——这正是 N5′ 三栏寿命纪律的要求。）

### （B）失败形态是可命名的

上一轮的 P1 证伪器在四个核臂**全部点火**；`F_f` 质量落在月初脉冲日的占比，
父控制 `P-upper = 0.16433099350243277`，而月初日只占天数的 `0.03285420944558522`
⇒ 过表征 `5.001824614730297` 倍。

### （C）水平统计量的身份未定 —— 这是本轮唯一真正的风险

`mean_concentration` 的实现已读实：它是**合格站日格栅上的比值的均值**
（`C = 1000·boundary_mass(local)/water_m3_day`，再取普通平均），不是比值；
而上一轮自己已把它的水量加权失配 `cov(dmass_t, 1/water_t)` 登记为**不进任何判据的诊断**。
⇒ 本轮把"水平—`τ_m` 曲线"作为**显式交付**，而不是把它当成一个已知的靶。

## 六、判决 —— **双层结构**

### 层 1（硬判决层，唯一能签发 capability）

`main_verdict_gates = ["G1","G2","G3","G5","G5b"]`，阈值与基线一个数都不改。

| 结局 | 条件 |
|---|---|
| `DUAL_PATH_CAPABILITY_DEMONSTRATED`（标签 `FULL_CAPABILITY`） | 主臂 `P-1e2` **同一个 `τ_m = 200.0 d`** 上五门全过 |
| `MOBILE_POOL_MAPPING_LIMITED` | 主臂不过，且 Γ 形态（`τ_eff ≪ τ_hydro`、月初脉冲、库存被水周转率抽空）在**主臂上任一成立** |
| `NO_AMPLITUDE_MECHANISM` | 主臂 `G1` 不过，且不满足以上任一条 |
| `BLOCKED` | N1′–N16 任一失败 |

**本轮实测**：`NO_AMPLITUDE_MECHANISM`。三个 Γ 形态条件在主臂上**全部不成立**
（见 §八）；`n_gamma_conditions_firing_on_the_primary = 0`。

### 层 2（shape 判据层，`enters_no_gate = True`、**不授权任何东西**）

存在的理由：`G5b` 量的是 `E[M_t/Q_t]`（比值的均值），受 `Cov(M_t, 1/Q_t)` 影响，
**它不适合单独承担"机制有没有 shape 能力"的裁决**。
所以两个科学问题必须拆开：问题 A（能否成为合格候选）仍由五个门答；
问题 B（`k_m` 本身有没有时间结构能力）由层 2 答，**而该层不授权任何东西**。

**F1（材料性改善）**：至少一个**候选** `τ_m` 上，`A_L1` 或 `A_L3` 把
"父控制 `P-upper` → 已注册门阈值"的差距补上 ≥ `0.5`：

```
(A_•(τ_m) − A_•(P-upper)) / (G_•^thr − A_•(P-upper))
```

其中 `A_L1(P-upper) = 0.7373725809958451`、`G1^thr = 1.1579754800655908`；
`A_L3(P-upper) = 0.7442117522548058`、`G2^thr = 1.1495455668222099`。
**四个锚点都是冻结读数，本轮的臂一个都还没跑时就算出来了。**

**F2（水平匹配点上改善是否基本消失）**：在 `τ_m^★` 上同一比值 < `0.15`。

| 结局 | 条件 | 授权 |
|---|---|---|
| `SHAPE_RESPONSIVE_BUT_LEVEL_COUPLED` | G5b 在主臂与全部候选臂上**均不过**；**且 F1 成立**；**且 F2 成立** | 不授权模型／重拟合／`k_ex`；只授权**下一轮另行预注册**去把"equilibrium mobile availability"与"transfer timescale"拆开 |
| `SHAPE_RESPONSIVE_AND_LEVEL_FREE` | F1 成立且 F2 **不**成立 | 只授权**下一轮在 `τ_m^★` 附近加密预注册网格** |
| `KM_MAPPING_NO_SHAPE_CAPABILITY` | **即使不看水平**，整条候选网格上**无任何点满足 F1** | **关闭这一阶 `k_m` 映射**；**不应继续扩成两参数模型** |
| `LEVEL_CURVE_NOT_MONOTONE` | N14 失败（`C̄(τ_m)` 非单调） | 停止求根、完整报曲线；层 2 按 F1 单独判定 |

**层 2 与层 1 的关系（N17 断言）**：层 2 的结局**只写进 `verdict.json::shape_layer`**，
**不进入 `main_verdict_gates`**，**不改变**任何门的 `passed`，**不改写**层 1 的判决。
**`FULL_CAPABILITY` 只能由层 1 签发。**

F2 **不成立**（`0.23176970947804762`／`0.27398785662708963`，均 > `0.15`），

### 6.1 shape 量集合 —— **不以 recentring 为唯一证据**

> **裁定（逐字）**："**我建议不要只用'去均值 NSE'。** 因为 $C'_t=C_t-\bar C+\bar C_0$
> 是**加法平移**，而我们的核心事件判据 $C_{peak}/C_{base}$ **不是平移不变量**。
> 一个较大的加法平移会直接改变事件比值。"

* **第一类（层 2 的主证据）**：`A_L1`/`A_L3`，以及**站内变异系数**
  `CV_s = SD_s / C̄_s` 与其对数误差 `e^CV_s = |log(CV_pred,s / CV_obs,s)|`
  ⇒ **不会把"整体放大 9 倍"误当成日尺度方差能力**。
* **第二类（只作诊断，不进任何门）**：月尺度 `r`、`SD_cand/SD_obs`、`centered-RMSE`。
* **recentring 的定位**：`level_variance.py` 的去水平 NSE **保留，但只作辅助**，
  **不得作为 matched-level 的唯一证据**。

## 七、精确水平匹配诊断点 `τ_m^★`（本轮最强的一环）

> **裁定（逐字）**："**这是我最建议增加的。** 不要指望固定网格恰好碰到 `G5b` 的那条极窄区域。

> `τ_m^★: C̄(τ_m^★) = C̄_frozen`，或者达到机器允许的最小差。
> **必须先验证 `C̄(τ_m)` 在所给区间内单调；若不单调就停止求根，完整报曲线。**"

* **目标只用 `C̄_frozen = 2.8234476727379607`**（`B0` 自己的值），
  **不读取任何观测 TN/NH₄ 浓度作为目标**（N15 断言：
  `observed_tn_read = false`、`observed_nh4_read = false`）。
* **不是拟合参数**：没有优化库、没有最小二乘、没有残差目标函数；**只有二分**。
  登记为 `ROOT_FIND_IS_NOT_A_FIT`。优化器断言：`scipy.optimize` **未加载**
  （scipy **包**因 pandas 而在场，但**子模块**不在，断言写在子模块上），
  `optimiser_calls_in_body = []`、`optimiser_imports_in_body = []`。
* **存在性由中值定理保证**：`τ_m ↘ τ_water` 时核趋近父控制（`C̄ ≈ 9.143688123572442 × C̄_frozen`），

## 九、闭式水平律 —— **登记为 Phase 0 解析预测 + 本轮最重要的预注册证伪器**

稳态、固定净输入、固定 `s_M`、忽略 demand／事件非平稳／路由反馈的解析解：

```
E/I = [ q / ((1-s_M) + s_M q) ] · [ g_u / ((1-s_M) + s_M g_u) ]
N^M(q) / N^M(1) = q / ((1-s_M) + s_M q)
d/dq [ q / ((1-s_M) + s_M q) ] = (1-s_M) / ((1-s_M) + s_M q)^2  ≥ 0
```

**它是不完整模型定理，不是完整 SPARROW 前向的严格等式**——
真实系统还有月初脉冲输入、crop uptake、mobile pool carry、`Q/V` 输出、
空间异质的 `s_M`、河网混合与浓度的**比值均值**。所以：

* 它**只能作为 Phase 0 解析预测注册**，**不能仅凭它取消实验**；
* 它的作用是提供一条**可证的、方向明确的 falsifier（P-A / P-E）**，由正式前向去推翻或确认；
* **它的理论支撑**（成熟模型确实不用单一率常数同时承担两件事）：
  SWAT+ 有 active/stable organic-N 池划分 + 独立的 pool transfer + 独立的矿化率，
  再把进入 NO₃ 池的 N 交给 mobile water 输送；HYPE 明确把 fastN/humusN
  与 soil-water IN/ON 分开。**本轮不加任何这些结构**——
  它只是"如果 P-E 成立，下一轮才有理论依据拆开两个职责"的出处。

### 9.1 闭式的四个读数（实测 `s_M` 带 `[0.9966033069492995, 0.9997228863464569]`、`g_u` 中位 `0.1687143749219422`）
