# `20260920_2` 专家诊断报告 —— 为什么"可动性"买不到振幅

> 本报告只做一件事：把本轮的读数**解释成一个机制级结论**，并划出下一步**能**与**不能**做什么。
> 全部数字都取自本轮已落盘、已哈希的产物；`n_fits = 0`、`fit_worker_calls = 0`。

## 一、诊断结论（先给结论，再给机制）

**结论**：`legacy → mobile` 的可动性映射**确实改变了"什么 N 能碰到水"，
但它改变的是**可达的量**，不是**可达的性质**；
而事件判据 `A = median(C_peak/C_base)` 对"可达的量"几乎不敏感。**

三条支撑读数，**同一次运行里同时出现**：

| 观测 | 读数 | 含义 |
|---|---|---|
| 跨两个数量级的 `τ_m`，`A_L1` 只动 | `0.8196184997235119`（`K-30`）→ `0.8340612498511533`（`K-365`） | 平台 |
| 跨 `150×` 的**水平**变化，`A_L1` 几乎不动 | 低端 `τ=3600` 处 `mean_concentration = 10.388353086369117`、`A_L1 = 0.8338001807974333`；高端 `τ = 10^6` 处 `0.06764583981654479`、`A_L1 = 0.8351210153984423` | **比值对尺度不敏感** |
| 把水平强行拉回冻结基线，`A_L1` 仍不动 | `τ_m^★ = 21104.573561789428 d` 处 `A_L1 = 0.8348555927188647` | 平台是**机制**的性质，不是水平的性质 |

> 第二行是本轮最关键的一条：**水平掉了两个数量级，事件比值没动**。
> 这不是"水平与 shape 耦合"，而是**在当前位置上二者本来就不耦合**——
> 所以"拆开 equilibrium availability 与 transfer timescale"这一步**本轮没有依据做**。

## 二、机制：`τ_m` 调的是"可达的量"，不是"可达的响应"

### 2.1 一条被本轮照实量到的守恒：**能碰水的总量是逐臂不变的**

在核里，抽完 demand 之后两个池的和与 `q_m` 无关：

```
nL + nM = P − U = av
pre + str = (nM + T) + (nL − T) = nL + nM = av
```

⇒ **在每一个 (t, r) 上，"可能被水带走的总量"是同一个数**，
`τ_m` 只决定它**有多少坐在 `pre`（暴露给 `g_u`）里**：
`T = q_m·nL` 大 ⇒ 大部分立刻暴露；`T` 小 ⇒ 大部分被留在 `str` 里等下一期。

**这解释了本轮真正做成的两件事**（两件同时成立，方向相反）：

| 现象 | 父控制 `P-upper` | 主臂 `P-1e2` |
|---|---|---|
| 月初脉冲过表征（`F_f` 质量月初占比 ÷ 日数占比） | `5.001824614730297` | `0.9246350263990235` |
| （`F_f` 质量月初占比 / 日数占比 `0.03285420944558522`；父控制读数 `0.16433099350243277`） | —— | —— |

⇒ **暴露被平滑了**：`τ_m ≫ 事件时长` 时，mobile 池不再"看见"输入的脉冲形状，
月末脉冲形态**不是被削弱，而是消失了**（从过表征变成欠表征）。
这是一个**真实的机制成果**，也是本轮唯一被 `τ_m` 有效控制的东西。

### 2.2 为什么平滑暴露**不等于**提高事件对比度

`A` 是 `C_peak / C_base`，其中 `base` 取事件前 7 天、`peak` 取事件窗口内。
一阶线性闸门能做到的只有两件事：**乘一个系数**、**加一段滞后**。

* **乘系数**：分子分母同时被乘 ⇒ **在比值里约掉**（上面第二行读数就是它的实测形态）。
* **加滞后**：`base`（事件前 7 天）已经带着抬升后的基流水位，
  而 `peak` 还在追赶 ⇒ **滞后只能压低比值**。

⇒ **一个不受水控制的时间尺度，无法制造"水一碰就跳"的对比度。**
制造对比度的唯一杠杆仍然是 `g_u = Qu/Vu`（水接触本身），而 `g_u` 是**逐臂不变的**
（`phase1_arms.json::q_arm_invariance::matches_the_frozen_arm_table = true`；
`lifetime_arm_invariance::n_sel_all_equal = true`）。

**这就是"先解决什么 N 能碰到水"这一问的答案边界**：
本轮**成功地**把 N 移到了能碰到水的一侧（状态分裂），
但**"碰到水以后走哪条路"这一步的对比度，本轮没有动到，也不该指望一个可动性率去动它。**

### 2.3 数值上的旁证：`τ_eff ≡ τ_water` 这条恒等式**结构性失明**

`τ_eff/τ_hydro = 0.996355630760417` 在本轮**仍然成立**，而且**必然仍成立**：
这一对量由水侧 carry `(1-g_u)·s_M` 构造，**不含 `q_m`**。
它**既不能确认也不能否认**本轮的打破——本轮真正的打破由**状态分裂**测量：

```
legacy_share_of_the_land_state_over_the_whole_record_on_the_primary = 0.9802002679151975
τ_m/τ_water = 36.956366138731504
```

⇒ **恒等式被打破了（这是真的），但打破恒等式所需的那个旋钮，恰好就是那个对事件比值无效的旋钮。**

## 三、闭式作为预注册证伪器：四条预测的完整下场

闭式（稳态、固定净输入、两池共用 `s_M`）：

```
E/I = [ q / ((1-s) + s q) ] · [ g_u / ((1-s) + s g_u) ]
```

| 预测 | 内容 | 实测 | 判定 |
|---|---|---|---|
| **P-A** | 水平统计量是**通量型** ⇒ 穿越点在 `6.9×10³ d` 量级 | `τ_m^★ = 21104.573561789428 d` ≫ `3.6×10³ d`；逐格带含实测值 | **确认**（点估计差 `3.0586338495347` 倍） |
| **P-B** | `C̄(τ_m)` 单调不增 | 9 点，`n_violations = 0` | **确认** |
| **P-C** | `A_L1` 先升后降 | 从 `0.7373725809958451` 升到约 `0.835` 后**不再回落**（`10^6 d` 处 `0.8351210153984423`） | **半确认**：字面证伪器未点火，但升幅只有门差距的约 23% |
| **P-D** | `q_m=1` 与 `P-upper` 逐位相同 | 24 通道 `np.array_equal` 全真，**零前向** | **确认** |
| **P-E①** | `C̄` 在 `[30, 3.6×10³] d` 上极差 ≤1% | 水平跨 `9.126634036647962` 量级移动 | **被证伪**（零前向即可从注册表自身看出） |
| **P-E②** | F1 成立（改善 ≥ 门差距一半） | 最好 `0.22988112794551832`／`0.27174197423503527` | **被证伪**（≈23%） |

**P-E 是本轮最重要的预注册证伪器，它被证伪了 —— 但方向与它的设计意图相反**：
它预测"单一 `k_m` 无法同时控制水平与时间结构"，
实测是**更靠前的一层**：**单一 `k_m` 连时间结构都控制不了**。
（这也正是为什么本轮的层 2 结局不是 `SHAPE_RESPONSIVE_BUT_LEVEL_COUPLED`。）

### 3.1 闭式的**绝对水平**仍被低估（必须照实写）

闭式按中位 `s_M` 给出的穿越点 `6900.0 d` 与实测 `21104.573561789428 d` 差 `3.0586338495347` 倍；
按实测 `s_M` 场逐格展开的**分布**包含实测值
（`τ_star_p25 = 2098.34954949243`、`τ_star_p75 = 13849.914196275286`）。
⇒ **"穿越点由 `s_M` 的空间散布主导"成立**，但"点估计准"不成立。
闭式是**稳态**解，而评估期只有 4 年，`s_M` 的隐含寿命带是
`[293.90371030790203, 3608.1276544444436] d` ⇒ **两个池都没有达到稳态**。
**计划的穿越带 `[2.4e3, 2.9e4] d` 不复现**（`plan_text_band_reproduced = false`），登记为偏离 B8。

## 四、判决：两层，各自的证据链

### 层 1（硬判决，唯一能签发 capability）—— `NO_AMPLITUDE_MECHANISM`

* 主臂 `P-1e2`（`τ_m = 200.0 d`、`q_m = 0.004987520807317687`）在
  `G1∧G2∧G3∧G5∧G5b` 上 **0/5**；`n_kernel_arms = 9`、`n_kernel_arms_passing_all_five = 0`。
* **不满足** `MOBILE_POOL_MAPPING_LIMITED` 的三个 Γ 形态条件中的**任何一个**：
  `τ_eff ≪ τ_hydro`（实测是 0.4% 以内的相等）、月初脉冲（实测欠表征 `0.9246350263990235`）、
  库存被水抽空（`τ_m/τ_water = 36.956366138731504`，库存由 `τ_m` 持有）。
* ⇒ 落 `NO_AMPLITUDE_MECHANISM`。报告须写明已依次排除：

  动员前路径特异浓度 → 守恒双水路浓度（零参数）→ **legacy/mobile 可动性映射（单参数、零拟合）**。

> **一处必须写清的边界**：`MOBILE_POOL_MAPPING_LIMITED` 这一行是留给"`k_m` 没能打破恒等式"的；
> 本轮**打破了恒等式**，所以它不是本轮的结局——这正是本轮相对上一轮**前进的地方**，
> 而前进之后停在同一堵墙前，说明**墙不是这一层**。

### 层 2（shape 判据层，`enters_no_gate = True`、不授权任何东西）—— `KM_MAPPING_NO_SHAPE_CAPABILITY`

## 十、下一步：能做什么、绝不能做什么

### 10.1 本轮授权了什么（逐字）

层 2 结局 `KM_MAPPING_NO_SHAPE_CAPABILITY` 的登记动作是
**"关闭这一阶 `k_m` 映射；不应继续扩成两参数模型。"**
⇒ **本轮不实现 `k_ex`、不预留开关、不扩成两参数模型**，
`SHAPE_RESPONSIVE_BUT_LEVEL_COUPLED` / `SHAPE_RESPONSIVE_AND_LEVEL_FREE` **均未触发**，
所以**"参数职责耦合"这条下一步理由本轮也没有拿到**。

### 10.2 为什么"拆开两个职责"本轮**没有**依据（把因果写清）

用户裁定里最有力的那一步是"若 shape 有、level 不行 ⇒ 参数职责耦合 ⇒ 下一步才有依据
把 balance mobile fraction 与 transfer timescale 拆开"。
本轮实测把这一条**排除在证据之外**：**shape 也没有**。
而且 §一 第二行读数给出了更细的理由——
在当前位置上水平与比例**本来就不耦合**（水平掉两个数量级、比值不动），
所以"拆开"不会改变比值，**拆开它只会拆掉一个不产生比值的东西**。
⇒ 需要拆的理由，**必须来自一条新的、另行预注册的证据**，不能从本轮读数反推。

### 10.3 理论出处（**是理由的来源，不是构建许可**）

成熟模型确实不用单一率常数同时承担"可动性"与"响应时间"两件事：
SWAT+ 有 active/stable organic-N 池划分 + 独立的 pool transfer + 独立的矿化率，
再把进入 NO₃ 池的 N 交给 mobile water 输送；HYPE 把 fastN/humusN 与 soil-water IN/ON 分开。
**本轮没有加任何这些结构**——把它写在这里，只是为了说明"如果将来要拆，
拆法本身在文献里有先例"，而**本轮不做这件事**。

### 10.4 明确不做

* 不实现 `k_ex`；不把 `k_m` 写成 `f(Q)·N^L`；不延长 `τ_m` 区间去追 `G5b`（那是照水平靶挑点）。
* 不引入 `Ξ`/`k_r`/`W`/`β`/cap/`min()`/任何乘子；不扩充 `g` 的取值集。
* 不事后放宽任何门、任何阈值、`ε_turn`、`MONTHLY_GATE`、`LEVEL_GATE`。
* 不让层 2 的任何结局读成 capability；不让 `τ_m^★` 承载任何门。
* 不为"采到交点"而事后加密网格——加密只能由**下一轮另行预注册**去做。

## 十一、一句话总结

> 本轮用一个状态对与一个标量率，**成功地**把 98% 的陆相 N 移到了"水控制不了"的闸门后面，
> 并**成功地**抹掉了月初脉冲形态；但它**没有**、也不可能买到事件对比度——
> 因为把 N 移到能碰到水的一侧，改变的是**可达的量**，
> 而 `C_peak/C_base` 对"可达的量"免疫（水平变化两个数量级、比值不动）。
> 事件对比度的杠杆仍然是"碰到水之后走哪条路"，而**本轮刻意没有碰那一步**。
