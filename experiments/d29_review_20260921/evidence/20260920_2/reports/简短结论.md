## 0. 一行结论

**单参数 `k_m` 打破了上一轮唯一未被击破的恒等式，但没有换来事件振幅。**

* **层 1（硬判决，唯一能签发 capability 的一层）**：`NO_AMPLITUDE_MECHANISM`。
  主臂 `P-1e2`（`τ_m = 200 d`、`q_m = 0.004987520807317687`，由**先于任何前向注册的盲规则**指定）
  在 `G1∧G2∧G3∧G5∧G5b` 上 **0/5**；**9 个核臂全部 0/5**。
* **层 2（shape 判据层，`enters_no_gate=True`、不授权任何东西）**：`KM_MAPPING_NO_SHAPE_CAPABILITY`。
  **即使不看水平**，`A_L1`/`A_L3` 在整条候选网格上都不向观测靠近：最好的 F1 比值是
  **`0.22988112794551832`**（`A_L1`，`K-365`）与 **`0.27174197423503527`**（`A_L3`，`K-3p6e3`），
  都远低于所需的 `0.5`。

> 按 §2.5 的登记表，这一行触发的是**"关闭这一阶 `k_m` 映射；不应继续扩成两参数模型"**。
> 但**本轮不把这句话单独当成最终判词**——因为最强的那个证伪器（§2.6 的 `τ_m^★`）
> 给出了一个必须同时读的结果，见下面第 3 条。

## 2. 但没有换来振幅：一条平坦的平台

```
A_L1（候选网格，六个点）
  K-30      0.8196184997235119
  K-90      0.8283682394174161
  P-1e2     0.8328411654810111   ← 主臂
  K-365     0.8340612498511533   ← 网格最大
  K-1e3     0.8334611007763244
  K-3p6e3   0.8338001807974333
------------------------------------------------
冻结基线           1.0400772083480145
G1 已注册阈值       1.1579754800655908
```

跨**两个数量级**的 `τ_m`，`A_L1` 只动了 `0.8196184997235119 → 0.8340612498511533`
（极差 `0.014442750127641402`），而且**全部落在冻结基线之下**。
换句话说：**给 N 一个不受水控制的寿命这件事，把振幅推向了错误的方向，然后停在那里。**

`A_L3` 同形（`K-30` 的 `0.827955825334509` 到 `K-3p6e3` 的 `0.8543579632495699`）。
站点离散门 `G3` 同样不过：主臂 `median_e(L3,ddof=0) = 2.358418293077076`，
阈值是 `0.5559042757541334`。

## 3. 最强的一环：把水平强行拉回去，振幅一点不剩地没回来

`τ_m^★ = 21104.573561789428 d` 是**二分**求出的点（不是拟合：目标只有冻结基线
`mean_concentration = 2.8234476727379607`，**不读任何观测 TN/NH₄**，
**不 import 任何优化机制**；N15 四条全部通过）。在该点：

| 量 | 平台值（候选网格） | `τ_m^★` 处 | 冻结基线 |
|---|---|---|---|
| `A_L1` | `0.834557` | **`0.8348555927188647`** | `1.0400772083480145` |
| `A_L3` | —— | `0.8552682953266111` | `1.023217381861253` |
| `mean_concentration` | —— | `2.8235113396138667` | `2.8234476727379607` |

**结论：把水平拉回去，振幅几乎没变（差 `3.0e-04`）。**
所以那条约 `0.835` 的平台是**机制的性质，不是水平的性质**——
无论怎么匹配水平都换不回事件对比度。

**这就是为什么这一轮不能用"去均值"论证代替它**：`C'_t = C_t - \bar C + \bar C_0`
是**加法平移**，而本轮的核判据 `C_peak/C_base` **不是平移不变量**；
`τ_m^★` 是**真的把前向重跑了一遍**，去均值从来不会重跑前向。

同一位置上月尺度结构是灾难性的：`nse = -1.3159861791622283`、
`median_station_nse = -7.744967993025499`，
且 `c_peak_L1 = 0.09406560652743748` **低于** `c_base_L1 = 0.11182194995692615`
——即"事件峰值低于基线"，事件的**符号**已经反了。

> **N16 红线**：`τ_m^★` 处的 G5b **是由构造满足的**，那里的 G5b 通过是关于构造的证据，
> 不是关于机制的证据；**它不承载任何门**，也不承载层 1 的任何结局。

## 5. 闭式：作为**预注册证伪器**的下场（两侧都要照实写）

闭式（稳态、固定净输入、两池共用 `s_M`）：

```
E/I = [ q / ((1-s) + s q) ] · [ g_u / ((1-s) + s g_u) ]
```

| 预测 | 内容 | 实测 | 判定 |
|---|---|---|---|
| **P-A** | 水平统计量是**通量型** ⇒ 穿越点在 `6.9×10³ d` 量级 | 实测 `τ_m^★ = 21104.573561789428 d` ≫ `3.6×10³ d` | **确认**（点估计差 `3.0586338495347` 倍，但**逐格带**包含实测值） |
| **P-B** | `C̄(τ_m)` 在注册区间上单调不增 | 9 点，`n_violations = 0` | **确认** |
| **P-C** | `A_L1` 先升后降 | 从 `0.7373725809958451` 升到平台后**不再回落**（`10⁶ d` 处 `0.8351210153984423`） | **半确认**：字面证伪器未点火，但实质上"升幅只有门差距的约 23%" |
| **P-D** | `q_m = 1` 与 `P-upper` 逐位相同 | 24 通道 `np.array_equal` 全真，**零前向** | **确认**（新核真的装上了的唯一证据） |
| **P-E①** | `C̄` 在 `[30, 3.6×10³] d` 上极差 ≤1% | 实测跨度为 `9.126634036647962` 量级的水平移动 | **被证伪**，且**零前向**即可从注册表自身的内部矛盾看出 |
| **P-E②** | F1 成立（改善 ≥ 门差距一半） | 最好 `0.22988112794551832`／`0.27174197423503527` | **被证伪**（≈23%，不是 ≥50%） |

补一条**必须报出的口径更正**：闭式按**中位** `s_M` 给出的穿越点估计是 `6900.0 d`
（计划也是这个数），实测 `21104.573561789428 d` 差 `3.0586338495347` 倍；
而按**实测 `s_M` 场逐格**展开的**分布**包含实测值
（`τ_star_p25 = 2098.34954949243`、`τ_star_p75 = 13849.914196275286`）。
所以"穿越点由 `s_M` 的空间散布主导"这句话**成立**，
但计划 §1.2 给的那个 `[2.4×10³, 2.9×10⁴] d` 区间**不复现**
（`plan_text_band_reproduced = false`），已登记为偏离 B8。
