## 一、本轮唯一的问题

$$\boxed{\text{只增加一个"legacy }N\rightarrow\text{mobile }N\text{"的状态和一个转移率 }k_m\text{，}
\text{在冻结水文、冻结 }s_M\text{、零新参数、零拟合下，}}$$
$$\boxed{\text{能不能在}\textbf{同一个 }\tau_m\text{ 上同时}\text{买到事件振幅、且不把长期平均水平推出冻结基线？}}$$

### 1.1 上一轮真正证伪的是什么（逐字保留，不得软化）

### 1.3 闭式（**登记为 `Phase 0 analytical prediction`，并同时是本轮最重要的预注册 falsifier**）

稳态、固定净输入、固定 `s_M`、忽略 demand/事件非平稳/路由反馈（`q_m = -expm1(-1/τ_m)`）：

$$\frac{E}{I}=\underbrace{\frac{q_m}{(1-s_M)+s_M q_m}}_{\text{legacy 侧的转移节流}}\cdot
\underbrace{\frac{g_u}{(1-s_M)+s_M g_u}}_{\text{mobile 侧的排空}} ,\qquad
\frac{N^M(q_m)}{N^M(1)}=\frac{q_m}{(1-s_M)+s_M q_m}$$

**它是不完整模型定理，不是完整前向的严格等式。** 它的作用是提供一条可证、方向明确的
falsifier（P-A / P-E），由正式前向去推翻或确认。**不能仅凭它取消实验。**
理论支撑（成熟模型确实不用单一率常数同时承担两件事）：SWAT+ 的
active/stable organic-N 池 + 独立 pool transfer + 独立矿化率；HYPE 的 fastN/humusN
与 soil-water IN/ON 分离。**本轮不加任何这些结构**——它只是"如果 P-E 成立，下一轮才有
理论依据拆开两个职责"的出处。

## 二、核（逐字，唯一拼写）

保留下来的：source ledger、crop demand、水文学、河道路由、观测算子、**冻结的 `s_M`**、
`g` 的两种拼写、`φ`、`V_u = upper_water + Qu`、`V_s = lower_slow_storage_mm + Qs`。
替换掉的：`A` 单状态 → 两个陆相状态。

```
# 状态：N^L（legacy，弱可动）、N^M（mobile 可达）、L（慢层，与上一轮同）
NL  = N^L[r] + inp[t,r]            # 输入入口在 legacy 侧（逐字）
NM  = N^M[r]
P   = NL + NM
U   = min(demand[t,r], P)          # demand 从两池按比例抽，参数-free
U_L = U * (NL / P) if P > 0 else 0.0
U_M = U - U_L
nL  = NL - U_L                     # 抽完 demand 后的 legacy
nM  = NM - U_M

T   = q_m * nL                     # legacy → mobile 的一阶转移
str = nL - T                       # N^{L,*}
pre = nM + T                       # N^{M,pre}

# 以下与上一轮逐字相同（同一个上层浓度、同一个 g、同一个分水）
Qu    = Qf[t,r] + Qp[t,r]
g_u   = g(Qu / Vu[t,r]) * guard[t,r]
E_M   = pre * g_u
phi_f = Qf[t,r] / Qu
F_f   = E_M * phi_f
J     = E_M * (1 - phi_f)
rem   = pre - E_M                  # N^{M,rem}
N^L[r] = s_M[r] * str
N^M[r] = s_M[r] * rem
Loss[t,r] = (1 - s_M[r]) * (str + rem)
Lpre = L[r] + J                    # 慢层与上一轮逐字相同
g_s  = g(Qs[t,r] / Vs[t,r])
F_s  = Lpre * g_s
L[r]  = Lpre - F_s
local = F_f + F_s + human_mass(t)
```

**六点必须同时成立，缺一即 `BLOCKED`：**

1. **输入只进 legacy 侧**（`N^{L,+} = N^L_{t-1} + I_t`、`N^{M,+} = N^M_{t-1}`），逐字。
2. **demand 的分抽是参数-free 的比例式**，三条严格断言：`U_L ≤ NL_+`、`U_L+U_M = U`、
   `P == 0 ⇒ U == 0`（不得出现 `0/0`）。
3. **`T^{mob} = q_m·Ñ^L` 与水文无关**；`k_m` 是**单个标量**，整轮**只此一个**，所有臂共用同一拼写。
4. **`contact <= 0` 只禁止水输出**：掩码上 `g_u = 0 ⇒ E_M = 0 ⇒ F_f = J = 0`，
   但 **`T^{mob}` 照常发生**，`N^L` 与 `N^M` 在掩码上照常演化。**这不是可选项。**
5. **数值拼写**：`q_m` **必须**写 $\boxed{-\operatorname{expm1}(-k_m)}$，**不得**写 `1-exp(-k_m)`
   （N12，写成断言而不是风格约定）。
6. **归约点存在**（N1′）。

**两个池共用冻结的 `s_M`**（§0.2 的关键纪律）：`Loss_t = (1-s_M)(N^{L,*} + N^{M,rem})`。
任何"legacy 用另一个 survival"的写法都是**新参数**，一律禁止。

> 而我们的核心事件判据 `C_peak/C_base` **不是平移不变量**。一个较大的加法平移会直接改变事件比值。"

**第一类：天然与 level 弱耦合 / 无关的 shape 量**（层 2 的主证据）：

* `A_L1 = median(C_peak/C_base)` 于 L1；`A_L3` 同形 —— **比值量，平移会直接改变它，
  所以必须与"水平是否移动"一起读，不能单独当 shape 证据**；
* **站内变异系数** `CV_s = SD_s / C̄_s`（同一站自己的尺度归一），及其误差
  `e^{CV}_s = |log(CV_pred,s / CV_obs,s)|` ⇒ **不会把"整体放大 9 倍"误当成日尺度方差能力**。

**第二类：月尺度 shape 诊断**（全部**只作诊断，不进任何门**）：`r_monthly`、
`SD_cand/SD_obs`、`centered-RMSE`。

**recentring 的定位**：`level_variance.py` 的去水平 NSE **保留，但只作辅助**，
**不得作为 matched-level 的唯一证据**。

> **⚠️ 同时登记的口径**：`CV_obs,s` 与 `centered-RMSE` 读取**月度观测面板**的**方差**，
> 走的是 `G5` 同一条只读路径（`obs_monthly()`，同一个 sha 断言）。它**仍然只读、
> 仍然不是任何拟合目标**，**登记为命名自由选择**（§十一第 11 项），
> 并明确它与 `mean_concentration`（水平门）使用**同一面板、不同统计量**。

## 十、预注册预测（含证伪器）

* **P-E（本轮最重要的预注册 falsifier，用户裁定升级）**：**"单一 `k_m` 很可能无法同时控制

  > `s_M` 异质性后果。**两者的关系写在报告里，不得互相顶替。**

## 十三、一句话摘要

> 上一轮把"legacy 库能不能直接当 mobile 库"判过了——**不能**。本轮只加**一个状态**和**一个率**：
> 输入先进 legacy 池，legacy 池以**一个与水文无关的时间尺度** `τ_m` 把 N 交给 mobile 池，
> 之后的一切（同一个上层浓度、同一个 `g`、同一个 `s_M`、同一条水路）**一字不改**。
> 它要打破的是上一轮唯一没被击破的恒等式 $\tau_N \equiv \tau_{\rm water}$（实测比 `0.9964`）；
> 而它的两端已被量到：水给 N 的寿命 **`5.4118 d`**，冻结模型给 N 的寿命 **`6934.728 d`**，
> 相差 **`1169.754×`**。
> **评估结论**：动态会质变（这正是恒等式被打破的含义）；量级在 `τ_m ≲ 2500 d` 的整条注册网格上
> 按闭式**几乎不动**，要落回水平门得走到 `τ_m ≈ 6.9×10³ d`（提案上界的 1.9 倍）、窗口 `±0.7%`。
> 逐格实测穿越分布：p50 **`6947.62 d`**、p25–p75 **`[2098.35, 13849.91] d`**、
> p05–p95 `[129.35, 47127.19] d` ⇒ **普通 log-grid 很可能"没采到交点"而不是"交点不存在"**。
>
> **所以本轮不按"一个硬门网格搜索"做，而按用户裁定的双层判决做**：
> **层 1** 五门一字不改、`G5b` 不动不降级不放宽（它继续是生产/晋级意义上的硬门），
> 唯一能签发 capability；**层 2** 是独立的 shape 判据层（`enters_no_gate=True`、不授权任何东西），
> 用**不与水平耦合**的 shape 量，并**不以 recentring 为唯一证据**（加法平移不是峰/基比的不变量）。
> 层 2 的三个结局正是本轮的科学产出：
> `SHAPE_RESPONSIVE_BUT_LEVEL_COUPLED`（**参数职责耦合** ⇒ 下一步才有依据拆开）、
> `SHAPE_RESPONSIVE_AND_LEVEL_FREE`（只差采点）、
> `KM_MAPPING_NO_SHAPE_CAPABILITY`（**关闭这一阶映射，不扩成两参数**）。
>
> **最强的一环是 §八的 `τ_m^★`**：只利用冻结基线 `C̄_frozen`、**不读观测 TN**、
> **不是拟合参数**（只有二分，没有优化机制），求一个"强迫水平与父模型相同"的诊断点；
> **它绝不能承载 G5b**（那里 G5b 由构造满足），只回答"把 mean 拉回去之后 `k_m` 还剩多少动态能力"。
> 求根前必须先证单调性（N14），非单调则停止并完整报曲线；两端点**实算并断言跨越**（不假定）。
>
> **闭式因此不是取消实验的理由，而是本轮最重要的预注册 falsifier（P-E）**：
> 它预测"单一 `k_m` 无法同时控制水平与时间结构"，**正式前向负责判断真实的非平稳、
> 空间异质与路由过程能否推翻它**。
>
> 主臂不看性能：`τ_m = √(5.4118 × 6934.7) ≈ 193.7 d → 200 d`（最近的注册对数网格点），
> 是"水给 N 的寿命"与"冻结模型给 N 的寿命"的**几何中项**，先于任何前向注册。
> 父归约（`q_m = 1`）**零前向**且与 `P-upper` **逐位相同**——
> 这是"新核真的装上了"的唯一证据。**零拟合、零新参数、`k_ex = 0`、30 维参数一字未改。**
