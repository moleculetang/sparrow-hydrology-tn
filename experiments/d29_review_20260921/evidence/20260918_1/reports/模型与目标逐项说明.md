## 2. FCT8 的正式构造

### 2.1 关键裁定：分解发生在 soft-saturation 的 **latent score** 上

用户明确否掉了"在最终乘子上做乘性分解"（`h·exp[L_m]·exp[·]`）与"线性替换 tanh"两条路，
理由是：**正在被分解的就是 `A_t` 本身**，把 `exp(A_t)` 放进权重或放进分解式等于
"用旧动态形状再给自己加权一次"，会双重放大高乘子日。

唯一实现口径：

$$u_{r,t}(v)=\frac{1}{\sqrt8}\,v^{\top}\phi_{r,t},\qquad
\mu_{r,m}(v)=\frac{\sum_{t\in m}w_{r,t}\,u_{r,t}(v)}{\sum_{t\in m}w_{r,t}}$$

$$b_L=b+\frac{\delta}{2},\qquad b_T=b-\frac{\delta}{2}$$

$$u^{FCT}_{r,t}=\mu_{r,m}(b_L)+\big[u_{r,t}(b_T)-\mu_{r,m}(b_T)\big]$$

$$A^{FCT}_{r,t}=B\tanh\!\Big(\frac{u^{FCT}_{r,t}}{B}\Big),\qquad
h^{FCT}_{r,t}=h^{preD29}_{r,t}\cdot\exp\!\big(A^{FCT}_{r,t}\big),\qquad B=\ln 10$$

**只有一次 soft saturation**，与 `D29_BE` 完全同一个非线性通道；乘子仍界在 ×[0.1, 10]。

### 2.2 它为什么正好就是"月水平 + 月内时序"

因为 `u` 对 `v` 线性、`μ` 对 `v` 线性，上式可完全展开，**无交叉项、无近似**：

$$u^{FCT}_{r,t}=u_{r,t}(b)
+\underbrace{\frac{1}{\sqrt8}\delta^{\top}\bar\phi_{r,m}}_{\text{月水平：月内常数}}
+\underbrace{\Big(-\frac{1}{2\sqrt8}\Big)\delta^{\top}\big(\phi_{r,t}-\bar\phi_{r,m}\big)}_{\text{月内时序：}w\text{-零均值}}$$

两个方向在 `w` 加权月内内积下**严格正交**，且都只由同一组 8 个 δ 驱动。
这是 F4 梯度解耦诊断能干净成立的原因。

### 2.3 2:1 杠杆不对称（**结构事实，不是缺陷，必须随件登记**）

水平系数 `+(1/√8)δᵀφ̄`，时序系数 `−(1/(2√8))δᵀ(φ−φ̄)`。因 `μ` 在 `u^FCT` 里出现**两次**，
**水平的有效杠杆是时序的 2 倍**。⇒ 拟合出的 `|δ|` 不能按 1:1 读作"水平/时序冲突有多大"，
时序那一侧要除以 2。本轮**保留**该不对称（它是 ±δ/2 对称位移的必然推论；换成对称效应需要
`b_L = b`，那会退化成纯时序模型）。

### 2.4 δ=0 是**代数精确**的 `D29_BE`

$$u^{FCT}(\delta=0)=\mu(b)+u(b)-\mu(b)\equiv u(b)\qquad\text{对任意 }w$$

实测（`reports\fct8_validation.json`）：latent 差 **4.44e-16**、
相对预测差 **5.92e-16**（D）／**3.64e-16**（M）、数据项差 **0.0**、先验项差 **0.0**、
总目标相对差 **0.0**。详见 `reports\fct8_nesting.md`。

| δ 参数 | 对应先验下标 |
|---|---|
| `delta_0 … delta_7` | `28, 29, 30, 31, 32, 33, 34, 35` |

`D29_BE` 的先验向量与 `FCT8` 先验的前 28 项**逐位相同**；
把 `δ` 任意改动**不改变**前 28 项中的任何一项。⇒ 嵌套在**先验层面**也成立。

## 5. `w` 与 `L_m` 的确切口径（用户裁定）

### 5.1 `w` 用 **pre-D29 base hazard**，**不冻结完整 D29 hazard**

$$\boxed{\,w_{r,t}=h^{preD29}_{r,t}(\hat\theta_{\rm ref})\,}$$

即 `scripts\campaign_model.py:129-133` 中**除最后一行 tanh 因子之外**的全部：

```python
def flux_parameters(self, t):
    h, s, f = Predictor.hazard(self, t[:29])          # 129-130
    shift = self.pi * (t[29] - t[1])                   # 131
    h = h * torch.exp(shift[None, :] * self.logcontact)  # 131
    # ← 截止到这里；下一行（132-133 的 einsum + tanh）不进入 w
```

在 H1-`D29_BE` 最优点上取值后**整轮冻结**，落盘并进哈希清单。
**不得**使用 `h^{D29} = h^{preD29}·e^{A_t}`：正在被分解的就是 `A_t`。

**两条随件结论**：

1. **`w` 的选择不可能破坏嵌套。** 因 δ=0 时 `u^FCT ≡ u(b)` 对**任意** `w` 恒成立，
   `w` 只进入 δ 方向（`reports\fct8_validation.json` V8 实测：δ=0 时把 φ̄ 置零，
   预测只变 1.78e-15；而 δ>0 时置零 φ̄，预测变 **12.44**）。⇒ `w` 的争议只影响 δ≠0 的行为。
2. **`w = 0` 的兜底。** `hazard` 用 `where(contact>0, exp(logh), 0)`，`contact = 0` 的单元
   `w` 恒为 0 ⇒ 月内 `Σw = 0`，加权均值无定义。这些单元回退**均匀月内均值**（自然极限，
   且由第 1 条兜底安全）。实测规模（D 折）：`cells_with_zero_weight_mass = 58`
   （占 58/176640 = **0.033%**）、`reaches_with_a_zero_mass_month = 33`、
   `min_positive_monthly_weight_mass = 3.001251710630605e-05`、
   `orthogonality_residual = 9.997076899785562e-16`。
   另有一个**不同**的量不可混用：`weight_fraction_exactly_zero = 0.149607549921138`
   （**14.96%**）是**条目级**"该月内部分日 contact 为 0"，不是单元级。

### 5.2 `L_m` 的权重与独立复核

`w` 的形状为 `(23741, 230)` float64 ≈ 43.7 MB/折，落盘并进哈希。
`build_phi_bar` 用 `np.add.reduceat(weight, starts)` 求 `w` 加权月内均值
—— 该函数在月轴非连续或未按 `mid` 排序时会**静默给出错误答案**（无异常、无形状错误），
而 `phi_bar[mid]` 仍自洽 ⇒ 代数恒等式查不出。
因此 `work\verify_fct8_weight.py` 用**独立路线**（逐月布尔掩码）复核：
重算 φ̄ 最大相对差 **4.74e-16**（D）／**4.75e-16**（M），定义性质
`Σ_t w(φ̄−φ)` 残余 **7.43e-15**／**1.35e-14**，均匀兜底差 6.04e-17，
`reduceat` 前提（0 个递减游程、游程边界 == `starts`、游程 id == `arange`）全部成立。
状态 `PASS_WEIGHT_VERIFICATION`。

## 6. 与 `D29_BE` 的**唯一**差别

`D29_BE`（`Endpoints.flux_parameters`，`scripts\campaign_model.py:129-133`）：

```python
u = torch.einsum('trj,j->tr', self.dynamic_basis, t[21:29])
h = h * torch.exp(math.log(10) * torch.tanh(u / math.log(10)))
```

FCT8（`scripts\fct8_model.py` `FCT8Tail.flux_parameters`）：

```python
b = t[21:29];  d = t[DELTA_INDEX]
bL, bT = b + d / 2, b - d / 2
muL = torch.einsum('mrj,j->mr', self.phi_bar, bL)[self.mid]
muT = torch.einsum('mrj,j->mr', self.phi_bar, bT)[self.mid]
u   = muL + (torch.einsum('trj,j->tr', self.dynamic_basis, bT) - muT)
h   = h * torch.exp(B * torch.tanh(u / B))
```

**`h_preD29` 的构造在两处逐字相同**；差别只在这两行。
`flux_parameters` **之后**的一切（M/L 递推、河网路由、水库混合、观测算子、目标、先验）
**原样继承**。

`scripts\campaign_model.py` 是本轮**唯一改动的既有核脚本**（它属于 `seal_global.py` 的核清单，
改字节不可避免）。处理方式不是"声称没改"，而是**证明改动是可加性的**：
`make_model()` 增加一条 `elif kind == 'FCT8'` 分派（`:165`），`D29_BE` 分支源码逐字符不动；
并用**逐位 replay**验收 —— 用 H1 域 + H1 参数重放，与 `20260917_5` 已发布的 H1 预测
**逐位相同**（5568 月行 + 169476 日行，gap `0.0e+00`，两折，14.46 s）。
详见 `reports\fct8_nesting.md` §8.2 与 `reports\独立完成审计.md`。

## 8. 判据口径（事前写死）

### 8.1 主判据：**同站配对**

$$\text{主判据}=\operatorname{median}_i\big[NSE^{FCT8}_i-NSE^{D29\_BE}_i\big]$$

**严禁**把 `median(NSE_cand) − median(NSE_base)` 的**次序统计量之差**当第一判据 ——
`20260917_5` 已实测它在 9/16 格上给出"合并报正、典型站变差"的假改善。它只作描述性并排给出。

### 8.2 晋级阈值（七条，**同时**成立才叫成功）

| # | 阈值 |
|---|---|
| 1 | 配对 `ΔNSE` 中位 ≥ **+0.10** |
| 2 | 配对 `Δr` 中位 ≥ **+0.05** |
| 3 | 站均 RMSE 比 ≤ **0.95** |
| 4 | 改善站比例 ≥ **60%** |
| 5 | `\|log SD ratio\|` 比基准下降 ≥ **10%** |
| 6 | 负相关比例**不增加** |
| 7 | 平均绝对 bias ≤ 基准 **1.05 倍** |

三层量级口径仍适用（`<0.05` 非常小／`0.05–0.10` 小幅／`≥0.10` "值得进一步验证"），
但**不与"是不是主要瓶颈"合并**。

### 8.3 结构性判据（与阈值并列，不得互相覆盖）

* 拟合后的 `cos(level, dynamic)` 与旧读数 **−0.9895** 对照；若 FCT8 生效，`|cos|` 应显著下降。
  **实测：未下降**（**0.98147 → 0.97975**，Δ **−0.00173**），见 `reports\专家诊断报告.md` §10.1。
  **命名更正**：本节与计划早前把该量写作 `cos(g_monthly, g_within)`，**是错的**；
  −0.9895 = `20260916_2\reports\gradient_information_audit.json` 的
  `geometry.scaled.cosines.level_dynamic` = **`-0.9895139119787311`**，
  即**月水平 vs 月内动态**，该产出者从未计算月尺度对月内尺度的余弦；
* `‖∂J/∂δ|₀‖` 的**预判 vs 实测**（预判见 `reports\fct8_nesting.md` §7；
  **实测**：δ 确被推动到 `|δ| = 0.580375`，但收益全在训练集内，2024 配对 ΔNSE **−0.01809**）；
* F1-5 的 δ–b 可辨识性（`max_abs_corr_delta_to_dynamic = 0.9372421233700994`，
  子空间最小主角 **12.92°**，故 δ 的实功**无法**与 b 的重参数化区分，必须写明）。

## 9. 本轮**不**做什么（用户 §19 逐条）

* 不继续标定水文；不调河道 `v_f`；不再加 β 端点；
* 不上更复杂的 LSTM/Transformer；**不训练更大的 TN LSTM**。
  ML 若回来，**只允许**用来学生成内部的 level/timing 参数或内部通量，**不得** `TN_pred = NN(X)`；
* 不把人口/不透水面直接塞进 TN 回归；
* 不再加一个通用的 M/L 交换池；
* **不同时**加污水 + PON + 新日历；**不同时**开几十条结构竞赛；
* 全程**不计算、不报告、不使用负荷**（所有判据落在浓度上）。
  `∂J/∂δ` 与 F6 的直排源包络**不是负荷判据**，是质量闭合审计。
