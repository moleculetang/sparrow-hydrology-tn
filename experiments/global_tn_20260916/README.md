## 本包内容与证据等级

`snapshot/scripts`、`snapshot/vendor`逐字节复制本次运行目录的 Python 文件；保留继承的辅助和非活动代码，避免删改源码破坏可核对性。**并非每个脚本和候选模型都在本轮执行**，以代码导航和 `evidence/configs/jobs.json` 为准。旧文件头中的 small-domain 等描述不能代替本轮配置。

`evidence/source_manifest.json`记录所复制文件的来源、大小、SHA-256。`evidence/algorithm_and_input_provenance.json`记录私有输入及继承算法来源，`input_layout`仅公开数组形状、类型、哈希，不含数组值。绝对Windows路径用于血缘记录，不是外部下载地址。

不上传原始CSV/工作簿、TN逐条标签、驱动数组、坐标/栅格、完整预测或拟合检查点。公开的汇总结果用于审阅科学结论，无法替代这些数据独立重现数值。原实验数据只读，本包不修改它。

## 已得到的结论

28/28路径通过原坐标梯度与物理合法性审计；小梯度不证明全局最优，部分双起点仍有明显目标差异。扩域改善了部分新增站和原X月面板，却未一致改善N/H；新增日信息的增益较小且依赖地点。棉江在全域时间折是训练地点，不能称空间留出。2025是延伸驱动敏感性，不能与2024正式检验合并认证。

公开合成测试见 `tests/test_public_kernels.py`，它们验证真实数值内核的局部数学性质，不重新执行1961年以来的真实数据验收。归档审计与本次发布测试分开记录。
