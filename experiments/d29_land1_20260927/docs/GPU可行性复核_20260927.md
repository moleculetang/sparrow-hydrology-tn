# LAND1 GPU 可行性复核（2026-09-27）

本复核只决定是否值得开发一个严格对照的 GPU 核；不把速度试验作为水质效果或正式训练证据。物理与优化性能的 NSE 不适用。

## 旧日志与当前变化

旧[全历史设备对照](../PRIVATE_DATA.md)在 23,376 日、230 河段上，E_EALSTM 的 CPU/GPU 为 16.39/31.18 秒，P_MCN3 为 26.66/211.98 秒；[2026-09-08 局地核对照](../PRIVATE_DATA.md)为 1.845/1.854 秒。它们都不是当前 LAND1 核，不能直接决定本轮设备。

本轮[当前完整目标剖析](../PRIVATE_DATA.md)在冻结 `LAND1_F23_T0_s0` 点进行了一次 1961—2024 全历史目标与梯度：122.69 秒，其中陆地前向核独占约 62.82 秒；年度输入构建累计约 37.63 秒，陆地反向核约 3.04 秒。`cProfile` 增加开销，分项累计时间有重叠，不能把它们相加当真实墙钟。原生产轨迹相邻调用约 132 秒。当前的 PyTorch 响应映射只占很小部分，单纯把它放到 CUDA 不会明显加速；需要移植陆地前向核及其真实伴随路径。

本机 RTX 4060 Ti 16 GB、PyTorch 2.13.0+cu126 可用。[单年 float64 试验](../audit/numerical_v2/gpu_one_year_pilot.json)在相同 365 日、230 河段、13 土地槽的简化输入上，Numba CPU 中位 0.4502 秒，Torch CUDA 中位 0.08674 秒，局地质量最大差 `2.89e-15 kg`，速度比 5.19。该试验没有土地转换、植物短缺、扩展库存、来源标签、反向伴随、河网、观测或恢复，因此**尚未证明完整 LAND1 可在 GPU 上等价运行**。

以当前完整目标约 51% 时间属于陆地前向核作乐观估计，即使这一部分取得简化试验的 5.19 倍加速、其余部分不变，整次调用约为 `1/(0.49+0.51/5.19)=1.70` 倍。这是上界情景而非预计交付速度。GPU 的 float64 吞吐、显存、年度 CPU↔GPU 传输及多 worker 争用仍需实测。

## 执行决定

完整历史的非负库存与来源前向验收现已通过，详见 `outputs/authoritative_safety_history/receipt.json`。但这不是完整 GPU 陆地实现的验收。未来若开发 GPU 后端，仍须在同一冻结输入、同一点比较一年和全历史的前向、目标及全部 23 坐标梯度；同时检查63组土地转换、每年状态与低位、来源账本和中断恢复。任何一项超原容差，GPU 不进入训练。若完整单调用加速不足或并发吞吐下降，保留 CPU 多 worker。

## 完整目标的 CUDA 映射实测

[完整历史 CPU／GPU 映射回执](../audit/numerical_v2/gpu_full_objective_mapping.json)在同一冻结点运行 CPU、仅将 H1 响应映射迁至 CUDA、再运行 CPU。三次目标完全相等；梯度最大绝对差 `1.09e-15`，映射动员风险差 `4.44e-16`，等价检查通过。CPU 两次分别 `129.83` 和 `135.17` 秒，CUDA 映射为 `140.20` 秒。该局部迁移没有速度收益，不能把简化陆地小核的 5.19 倍外推成完整目标速度。此次测试中 LAND1、来源、河网、OU 和伴随仍在 CPU；当前**不启用 GPU 训练后端**。
