# LAND1 数值修正与 CPU/GPU 实验：实际方法与偏离

本次记录对应 `20260927_2` 的冻结研究配置。用户将当前交付收窄为数值修正、验收、设备对照与代码 PR；原训练 worker 在核对 PID 和创建时间后停止，检查点与累计调用保留，没有重开正式拟合或读取评价年 TN 来选择修正。总预算延至 192 小时，见 `config/clock.json`；本次交付不把剩余额度自动用于训练。

## 数值故障与修正

最初发现的年度初态负数为浮点舍入量级，例如 1972 年 reach 228、土地槽 2 的可用氮为 `−9.09e−13 kg`。此前修正仅允许年度链接入已登记、绝对值不超过 `1e−9 kg` 的舍入表示，并未裁剪库存、放宽 `1e−7 kg` 非负门，也未修改显式初态验证。九条受影响路径逐条核对原检查点、异常签名、优化状态和目标梯度后迁移；原最佳点目标及梯度差均为零。

后续完整历史审计定位到大库存和来源标签长期累积的舍入误差。当前 `precision_candidate.py` 保留库存高位及低位补偿，仅在极小余量或负表示处改用直接非负通量公式；土地转换使用守恒的展开求和，标签按实际各来源质量分配。第一次把全部运输库存改为直接公式的尝试使多年来源标签失配，失败实现和证据保留在本实验目录；当前候选不沿用该失败规则。所有改动只涉及算术与状态表示，没有加入氮源、调整损失率、用 TN 残差补质量或改变 H1 水文。

前向／反向植物耗尽分支原来使用不同的浮点判据，现让伴随重放前向稳定判据。H1 响应映射先在对数空间合并，再作有界指数，避免中间乘积上溢；真实冻结点概率差仅在浮点误差量级。保留独立小核、错误反例和完整历史导数检查。折点差分单列，不用单侧吻合冒充光滑梯度。

## 验收方法

在 CPU float64、每进程一线程上，以相同 1961—2024 输入、230 河段、13 土地槽重跑全部 23,376 日。分别验收局地质量、来源标签、网络、水库、非负库存、植物预算以及旧新外部来源与计划哈希。判据不改：局地与来源最大绝对误差 `≤1e−6 kg`，网络误差 `≤通量尺度1e−10`，非负与摄取超限 `≤1e−7 kg`。独立目标用另一条计算路径重算；完整 23 坐标解析梯度按固定三步长检查，相邻两档合格才通过，折点另记录分支并细查。

完整梯度扫描按不重叠坐标分段运行。各段必须独立重算相同基点目标与梯度、匹配源码哈希，并在安全边界保存；合并脚本拒绝缺号、重叠、身份变化或不同基点。分段仅改变验收的并发，不改变模型目标或最终判据。

实际扫描合并 23 坐标、147 次累计调用；22 坐标按原三档通过，坐标 6 原扫描仍标失败。该坐标在 `1e−6` 负向发生一次摄取分支切换，`3e−7` 与 `1e−7` 双侧均无切换且误差达标；经 `derivative_gate.refinement_passes` 独立检查后才登记局部光滑导数通过。合并后的正式门返回 `passed=true`、无阻塞项。主段起初未收录四个较宽的输入／映射身份哈希；合并器核对四文件在主段启动前已固定、所有分段哈希一致且当前未改后补足完整身份。原主段、各段和细查回执全部保存，不以合并文件覆盖原失败事实。

工程测试在私有实验源码上运行完整合成夹具；公开副本另用审计钩子禁止访问 `E:/SPARROW/5_Test/`，只运行无私有数据测试。物理、梯度和速度量的 NSE 均不适用；本次没有产生可报告的新 TN 预测 NSE。

## CPU/GPU 方法及边界

一项 365 日、230 河段、13 土地槽的简化 float64 陆地前向试验只用于估计硬件潜力。它缺少土地转换、完整植物限制、来源标签、全历史伴随及河网。另一项在真实 1961—2024 目标与梯度上依次测 CPU、仅将 H1 响应映射迁至 CUDA、再测 CPU；使用同一冻结参数和输入，比较目标与全部 23 梯度。后一项并非 GPU LAND1 后端。完整 GPU 后端未实现、未通过同等验收，正式训练保持 CPU。

## 与原训练计划的偏离

本次没有派发 LAND1 修订后的正式训练，也没有打开 2023/2024 留出成绩。此前停下的 U/LAND1 队列、调用数、检查点和失败记录均保留。当前数值合格只能说明登记配置在验收门内运行，不能说明氮源真实、H1 同站界水量准确或新结构改善 TN 动态。以后若恢复训练，必须由冻结的新版数值门与本折合法检查点启动，并重新评价逐站日/月内 NSE；旧版目标值不能与新版结果混作同一数值轨迹。
