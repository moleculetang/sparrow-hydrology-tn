# 专家数值与设备审计报告：LAND1 修订候选

## 审查结论

**本轮修正了可复现的计算精度与伴随分支问题，完整历史的质量、来源、非负性和独立目标验收已通过；它尚未证明实测 TN 的振幅、相位或 NSE 改善。** 用户要求在完成数值与设备审计、提交 PR 后再讨论训练，因此原正式优化在保存检查点后停止；本轮没有产生新的留出预测。质量和速度量的 NSE 不适用，真实水质 NSE 须待修订版重新拟合并冻结评价后报告。

前一审阅快照的大库存局地质量误差约 `1.1444×10⁻⁵ kg`、来源差约 `5.4479×10⁻⁵ kg`，超过各自 `1×10⁻⁶ kg` 门槛。当前修订候选在同一 1961—2024、230 河段、13 土地槽连续历史上分别为 `1.2148×10⁻⁷ kg` 和 `9.4427×10⁻⁸ kg`；网络相对误差 `3.05×10⁻¹⁷`，非负库存及植物预算通过。改善是数值守恒的证据，**不能直接解释为水质误差下降**。

外部来源、来源标签及计划去向的 64 年数组哈希全部未变。内生植物年度目标依赖前一年模拟植物库存，因此在数值递推微变后有 62 年目标数组哈希变化；年末各库最大差 `2.384×10⁻⁷ kg`、最大相对差 `1.99×10⁻¹³`。这是模型内反馈的浮点效应，不是新的实测资料。独立目标重算均为 `282.1385700339797`，差零；该冻结点并非 LAND1 最优解。

## 梯度与求解

完整 23 坐标历史导数按 `1e−5`、`3e−6`、`1e−6` 三档差分检查，至少相邻两档合格才通过；耗尽折点另做左右分支记录。分段并行只用于缩短审计墙钟，各段重算同一基点目标与解析梯度，并校验源码哈希、坐标不重叠及完整覆盖。原三档中 22 坐标通过，`gamma_contact_3`（坐标 6）只在最细原档合格，因此原失败状态保留。它在 `1e−6` 的负向扰动有一次摄取分支切换；另行固定 `1e−6/3e−7/1e−7` 三档，其中后两档双侧均无分支切换、误差分别 `2.04×10⁻⁷` 和 `8.67×10⁻⁷`，低于未修改的容差。独立门仅接受这两档连续、无切换的局部光滑导数证据。

各段的基点目标与 23 个解析梯度完全一致；合并后坐标恰为 0—22、无重叠，记录 147 次累计目标调用（含各段重复基点计算）。主段原回执缺四个较宽的身份哈希，合并器核对它们的文件修改时间早于主段启动、与各独立分段哈希一致且当前未变，再将完整身份写入合并回执。[正式数值门](../audit/numerical_v2/formal_gate.json)返回 `passed=true`、`blocked_by=[]`。这使当前核具备数值验收资格，**不代表任何已停优化路径达到原坐标投影梯度 `≤1e−5` 或真实 TN 校准成功**。

本轮 104 项工程测试和 9 项独立小核／年度链测试通过。公开副本禁读本机实验目录，83 项合成测试通过；修改评价 TN 后预测、训练分组、尺度和初始化保持不变。测试通过不等于优化器的原坐标投影梯度 `≤1e−5`，亦不等于某条策略达到数值充分。

## CPU/GPU 实测与决定

当前 RTX 4060 Ti 可运行 float64 CUDA。简化的一年陆地前向中位 CPU `0.4502 s`、GPU `0.08674 s`，约 `5.19` 倍；该核没有 63 组土地转换、完整植物限制、来源标签、伴随、河网或检查点恢复，不能用于真实拟合。完整历史目标的时间剖析约 `122.69 s`，其中 LAND1 前向约 `62.82 s`，说明若开发 GPU 后端必须移植真正的陆地递推及其梯度。

在冻结的 64 年完整目标上，仅把 H1 响应映射移到 CUDA，CPU 前后两次分别 `129.83/135.17 s`，CUDA 映射 `140.20 s`。目标完全一致、最大梯度差 `1.09×10⁻¹⁵`，因此该局部设备路径等价但更慢。**本次不启用 GPU 训练后端**；简化核的速度潜力不构成完整 GPU 实现的验收。审查后的有限训练仍应采用 CPU float64 和内存峰值限制，而不是根据单项 GPU 倍数估算整体加速。

六个单线程完整梯度 worker 加一个折点诊断时，现场提交内存约 `84.7%`、物理内存约 `66%`、整机 CPU 约 `27%`。并发受提交内存与每 worker 峰值预留约束；继续为追求 CPU 100% 增派会逼近原 90% 暂停门。该资源快照解释本次并发选择，不是长期性能上限。

## 对 TN 动态问题的含义与剩余缺口

这次修正的是已经量化的计算误差和可能妨碍优化的数值故障，没有改变来源日期、年份替代、植物／土壤过程参数、H1 同站界水量、河内输运或观测算子。因此不能从守恒误差降低推断站内波动会恢复，更不能把旧条件前向的负 NSE 重新解释成已解决。修订版尚未在 2016—2024 全站月度和高频支持上重新拟合，真实日 NSE、月内中心化 NSE、事件峰日与空间留出结果均**未产生**；共同站数、NSE 配对中位数及改善站比例也不应填旧值。下一步需先用修订后的合法检查点完成数值充分的训练，再冻结预测，按已登记全站支持独立计算这些指标。即使成绩改善，来源情景与 H1 水量仍需独立认证。
