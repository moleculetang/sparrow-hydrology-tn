# 土壤温度核查与矿化方程选择

2026-09-27。本项结论：本地确有土温，但不足以无补值地支持1961—2024完整历史，因此主配置采用固定有效速率的一阶矿化。温度接口已实现、未在完整历史配置中启用。本报告不是新模型TN效果报告，NSE不适用。

## 原数据实际核查

已打开19份ERA5-Land月均NetCDF，覆盖2006-01至2024-12，共228个月。四个变量`stl1`—`stl4`均为K；官方层深为0—7、7—28、28—100、100—289 cm，不能把第一层单独叫作0—30 cm土温。全历史所需768个月中缺540个月，即1961—2005。另打开468份本地逐小时PET文件检查变量目录，其中没有土壤温度变量；里面的`t2m`是气温，不能按名字相近直接替代土温。湖混合层温度和地下水温度也不能替代陆地表层土温。

证据：[逐月分层清单（本地证据未公开）](../PRIVATE_DATA.md)、[缺失月份（本地证据未公开）](../PRIVATE_DATA.md)、[文件哈希与选择回执（本地证据未公开）](../PRIVATE_DATA.md)。原数据位于`0_reach_topology/data/raw/atmosphere/meteorology/era5_land/data/monthly_prb_buffer`。产品定义来自[Copernicus官方说明](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-land-monthly-means?tab=overview)，网页快照保存在本轮`evidence/literature/era5_land_monthly_official.html`。

月均土温可以约束已有时段的季节变化；它不提供逐日事件土温。将月均温复制到每天或进行插值仍是一种时间分配假设。尤其Q10非线性下，月均温对应的速率不等于月内逐日速率平均值。本次没有通过复制年份、气温替代或拼接不同模式来补足历史。

## 已写入代码的固定式

对两个SON库分别使用：

\[
K_{i,t}=S_{i,t-1}\left[1-\exp(-k_i\Delta t)\right],\qquad i\in\{a,p\},\quad \Delta t=1\;\mathrm{day}.
\]

实现采用`-expm1(-k*dt)`，不是大步长Euler扣减；当天新施有机氮和植物归还仍从次日起矿化。研究参考值为活性库`k_a=ln(2)/90 day^-1`，受保护库`k_p=1/(270×365.25) day^-1`。活性库用“90天释放50%”作为明确的研究时间尺度：中国秸秆论文表2提供当季释放45.11—54.04%的量级，但没有证明每项试验均为90天。受保护库借鉴固定版本CTSM的慢周转尺度。**适配成LAND1独立直接释氮速率是研究假设**，尤其秸秆N释放不等于净SON矿化；不能据此认证当前混合活性库。SWAT的CMN=0.0003仍登记为文献证据，但不直接应用于所有新鲜有机输入，避免把腐殖质周转因子当作新鲜残体的日矿化率。

参考值及逐项适配说明在[矿化配置（本地证据未公开）](../PRIVATE_DATA.md)。它们对应约130天和270年的e折时间，不能声称会自动解决输入波形过滤；必须与实际供氮、植物摄取、库存变化一并诊断。缺乏温度资料不等于这些速率已获独立认证。

## 保留但未启用的温度接口

\[
k_{i,t}=k_{i,\mathrm{ref}}Q_{10}^{(T_{soil,t}-T_{ref})/10},\qquad
K_{i,t}=S_{i,t-1}\{-\operatorname{expm1}[-k_{i,t}\Delta t]\}.
\]

固定版本CTSM给出Q10=1.5和参考土温25°C，可作为将来的研究参照；其原分解模块还包含水分、氧气和深度调节，本接口不冒称完整复现。若将来采用0—30 cm有效土温，可显式登记`(7 stl1 + 21 stl2 + 2 stl3)/30 - 273.15`的厚度加权近似，但仍须验收230河段的空间支持和缺测，不能由现有文件存在即自动启用。

代码：[mineralization.py（本地证据未公开）](../PRIVATE_DATA.md)。两库概率能够直接传给LAND1已有接口；完整历史伴随的概率梯度通过独立链式接口传回矿化率及土温参数。没有修改LAND0。

## 实际验收及边界

[验收回执（本地证据未公开）](../PRIVATE_DATA.md)记录11项检查、12项多步长梯度比较，均通过。使用1961—2024的23,376天合成历史，核对解析库存终值、新有机输入次日矿化、守恒、固定式在参考温度处嵌入温度式，以及未来土温不影响过去。非法参数、缺测土温和固定模式偷偷传入土温均被拒绝。

这些证明新增方程及导数接口可运行，不证明实测TN的NSE或振幅已经改善。本轮新输入全链条运行仍须完成其余来源、植物去向和空间支持矛盾的处理；本项没有将这些缺项改成已解决。
