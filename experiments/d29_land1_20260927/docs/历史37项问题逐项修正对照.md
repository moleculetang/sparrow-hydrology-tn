# 37项历史缺口对新模型的逐项审查

2026-09-27。依据上一轮37项登记逐一核对。工程通过、条件情景、未解决科学问题分开；没有将真实TN问题标为科学闭合。

## 1. land_inventory_filtering

原问题：陆地库存过滤输入尖峰、响应偏慢

**候选已改，科学未关闭**。本轮：以Sa/Sp矿化、植物及可用池替代原M；退出旧M寿命；完整历史运行。

仍缺：活性矿化仍为固定90天半衰期情景；未做同参数单因素归因或证明动态最优。

证据：[land1.py](../d29_platform/land1.py)。

## 2. observed_amplitude_phase

原问题：真实TN振幅不足、峰日和月内波形对应不充分

**已评价，未解决**。本轮：日/月内NSE、幅度、相关、峰日按共同支持重算。

仍缺：振幅提高到1以上而偏差和多数动态误差扩大；不能把增幅称为修复。

证据：[2024_daily_summary.csv](../audit/supply_limited_reference/evaluation/2024_daily_summary.csv)。

## 3. monthly_support_45

原问题：45个月站不受旧13区反推源影响

**覆盖接口已扩展**。本轮：新独立源覆盖230河段，输出全部116站界，不再限旧13区反推支持。

仍缺：未删45个月站；新的完整源仍不等于已确认真实负荷，旧反推结论不改写。

证据：[receipt.json](../audit/input_contract_audit/receipt.json)。

## 4. historical_initial_state

原问题：历史来源/需求与2021初态不可识别

**明确情景，未识别**。本轮：登记现代SOC/14初态、64年连续源和植物活动、初态来源标签。

仍缺：2024局地出口约25%仍来自初态标签；1961真实SON及历史植物活动未知。

证据：[annual_local_export_source_fractions.csv（本地证据未公开）](../PRIVATE_DATA.md)。
