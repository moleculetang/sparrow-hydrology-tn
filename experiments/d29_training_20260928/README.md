# D29 长序列与全域训练策略：代码和汇总审阅包

本包是 `20260928_1` 实际运行源码的字节快照，叠放在 `d29_land1_20260927` 审阅包之上。两者都属于研究实验，**不会自动替换主线模型或启动训练**。本次 32 条路径已经结束，24 个配置仅依训练目标选点，再冻结预测和计算 2023/2024 回顾性留出成绩。完整的科学解释、实际方法和偏离见[专家科学复核报告](reports/专家科学复核报告.md)、[全域验证报告](reports/专家训练策略与全域验证报告.md)、[训练期核查](reports/训练期2016-2022TN效果核查.md)和[实际方法](reports/实际方法与偏离.md)。

## 路径名称和比较范围

| 片段 | 含义 |
| --- | --- |
| `U` / `LAND1` | 原统一来源校正 D29/LAND0 / 植物、土壤与可用氮候选；两者来源和植物活动配置也不同 |
| `F23` / `F24` | 训练分别截至 2022 / 2023；回顾性评价 2023 / 2024 |
| `T0` | 从 2021 年起的近期月报权重 0.8，加 HF 月内异常权重 0.2 |
| `T1` | 月报扩至 2016 年，保持 T0 权重 |
| `T2` | 长记录站月报权重 0.4、其余站 0.4、HF 异常 0.2 |
| `s0` / `s1` | 预登记优化入口编号，**不是站点** |
| `S56` / `S113` / `S191` | 冻结的支流空间留出块；留出和影响缓冲站不参与该路径训练 |

例如 `LAND1_F23_T2_s1` 是 LAND1、训练截至 2022 年、T2 权重、入口 1。不同策略的训练支持和目标权重不同，不能直接比较目标函数数值。U 与 LAND1 只能作为完整配置比较。

## 结果入口与证据边界

训练期 2016—2022 月报逐站 NSE 中位数（116 站）：U T1/T2 为 −0.296/−0.365，LAND1 T1/T2 为 −0.882/−0.672。T0 仅训练 2021—2022，不能把 2016—2020 回算称作训练表现。[训练期摘要](audit/training_period_summary.json)及[逐站指标](audit/training_period_stations/)保留实际支持、NSE、RMSE、偏差、相关和幅度。2023/2024 留出效果见[配对汇总](audit/paired_summaries.json)和报告；2023/2024 LAND1 T2 的 HF 日 NSE 中位数 −0.847/−0.675，低于同折 T0 的 −0.474/−0.391。改善比例、月内 NSE 和共同站数在报告中分别列示。

[独立复核](audit/scientific_independent_review.json)核对 32 条路径、24 个选点、60 份配对表、160 份抽样回执和 20 份事件回执的内部一致性。LAND1 两条 T2 时间路径续训后梯度充分；`LAND1_S56_T2_s0` 梯度仍为 2.073×10⁻⁵，超过 10⁻⁵ 门槛。数值充分不等于输入真实，也不保证留出 NSE 改善。

## 源码和运行

`d29_platform/`、`d29_training/`、`scripts/`、`tests/`、`config/` 是本轮实际源码与登记配置；`vendor/` 是上轮已公开审阅的兼容依赖。所有文件的工作区 SHA256 在[source_manifest.json](source_manifest.json)。本包保留正式训练、验收、续训和报告脚本；私有输入缺席时只能运行合成检查，不能重跑真实 TN 拟合。[依赖](requirements.txt)按 Python 3.11 环境登记。可在本目录执行：

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
$env:OPENBLAS_NUM_THREADS='1'
python verify_public.py
```

公开检查拒绝读取 `E:/SPARROW/5_Test` 私有实验目录。完整真实运行需要冻结的 H1、来源与植物活动、230 河段拓扑/水库、OU 站界及观测表；原始监测值、驱动数组、栅格、逐日预测、优化检查点、缓存、密钥和环境均未发布。审阅包内报告引用的私有归档和逐日文件未上传，公开证据入口以本 README 链接为准。

2023/2024 已被多轮查看，本轮是冻结设计下的回顾性比较，不是新盲测。物理、优化和性能指标的 NSE 不适用；零观测方差或覆盖不足不强算 NSE。NH4/DO 按研究决定未进入训练或常规诊断。
