# 专家审计问题的实际处理

依据：用户提供的《PR #5 修订版：观测—目标—执行链审计与下一阶段建议》。本表记录实施身份，科学效果须等冻结预测后判断。

| 审计项 | 本轮处理 | 证据及仍有限制 |
|---|---|---|
| E01，旧新同 ID 目录混读 | 训练、审计、账本、冻结、选点和评价均定位新 `ExperimentContext` 的 `outputs/jobs`，缺点拒绝回退 | `tests/test_experiment_context.py` 的冲突反例及 `config/experiment_context.json`；仍需真实路径完成后核对全链 |
| E02，实际核依赖运行时赋值 | `Land1Training` 显式把 `precision_candidate` 传给 `AnnualChain`，worker/冻结回执写执行模块和哈希 | 新全历史目标回执中实际核 SHA256 与磁盘一致；不把核存在等同实际运行 |
| O01，官方月报读数权重 | 月报身份按用户确认的自动监测有效读数算术均值；模拟采用等日近似并逐行登记 | 完整官方有效读数次数仍缺，不宣称算子完全一致 |
| O02，HF 日覆盖过宽 | 规定四个不同有效时间且至少跨 12 小时；合格月还需两个合格日 | 12,152 个有 TN 读数站日中 9,716 日通过；保留 2,436 日不合格支持清单，不按残差删值 |
| O03，naive 时区风险 | 实际规范时间戳已核实带 `Asia/Shanghai`；读取器拒绝未声明时区的时间，跨闰月转换单测通过 | 原始档案以后有新的时间格式时须先声明时区 |
| T01，策略改变方差尺度 | 同折各策略固定近期训练期资料方差尺度 | 历史加入仍改变站内年度权重，结果称完整训练策略比较；权重变动单列 |
| T02，长站和桥接站混淆 | 同时输出早期充分站与早近桥接站；当前两者均为54站 | 整理后坐标在年际间稳定，但原站址迁移未获独立历史档案认证 |
| T03，稀疏站年单条过重 | 不删除稀疏年，将其总年度支持按 min(合格月数/6,1) 折减并站内归一 | `outputs/training_weight_audit.csv` 列最大单条权重和有效样本数；目标已变，旧曲率不得续用 |
| T04，HF 月内中心化 | 保留原正确反传，不重复计 HF 月水平 | 官方月报与局部HF可能同源，月块配对抽样考虑时间相关；不称独立观测 |
| T05，入口数不同 | T0/T2时间路径各两入口，T1仅一入口并标为历史增量辅助；空间 T0/T2均一入口 | T1 单入口局部解不能作为历史信息阴性定论；若证据指向起点敏感，后续需补等额入口 |
| T06，T2组权重实际效应 | 全域F23为长组54、其他62；各占0.4时每长站相对T1约提高 (54+62)/(2×54)=1.074 | 空间块组大小和实际权重逐折见训练权重表，不能只看0.4/0.4名称 |
| S01，固定SON/植物配置 | 保留条件性参数责任，不宣称23参数已反演矿化或初态 | 留出 TN 收益也不能认证真实SON参数；须独立土壤/植物证据 |
| S02，U/LAND1科学配置不同 | 仅在模型内部比较 T0/T1/T2；模型之间标完整配置比较 | 不把差值唯一归因陆地结构 |
| 附加数值分支风险 | 加入非零低位、土地转换、植物近耗尽同现的前向/伴随梯度回归 | `tests/test_precision_transition_branch.py` 两个相邻差分步长通过；仍不覆盖所有真实分支 |
| A01—A03，NH4/DO建议 | 按用户本轮决定暂不纳入 TN 拟合、预测变量及常规分层 | 不构造无 DO 状态的残差，也不以不同采样时刻强加氨氮/TN关系 |

物理/优化量不适用 NSE。真实水质的逐站 NSE、月内 NSE、共同站数和配对收益须以完成训练、独立复算、冻结预测后的结果为准。
