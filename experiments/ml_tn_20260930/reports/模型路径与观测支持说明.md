# 模型路径与观测支持说明

本文件解释本轮路径和读出，不提供尚未完成的效果结论。最终结果以《专家机器学习与全域验证报告》、冻结预测和独立复算回执为准。

## 路径如何读

例如 `F23_daily_CatBoost_c4_s1729` 表示：训练至2022年，以CatBoost预登记配置4和随机种子1729拟合HF日TN，读出2023年。`F24_monthly_CatBoost_c2_seedmean` 是三个已登记种子的**预测平均值**在2024年的官方月报支持上计算的结果；不是三条NSE的平均值，也没有在评价年选择某个种子。

| 字段 | 含义 |
| --- | --- |
| `screen` | 截至2021训练、2022年1—9月选择的内部筛选，不是2023/2024的预测成绩 |
| `F23` / `F24` | 分别训练至2022/2023，读出2023/2024；为冻结设计下的回顾性时间评价 |
| `S23` / `S24` | 同一截至2023的合法区域训练模型，分别读出2023同年空间留出和2024时空联合留出 |
| `B56` / `B113` / `B191` | 三个冻结支流块；留出及其下游影响站的全部年份水质从训练排除 |
| `c0`—`c7` | 已预登记的配置编号，不是按评价年排序的名次 |
| `s1729` / `s1730` / `s1731` | 三个固定随机种子；相同种子跨操作系统不保证随机训练轨迹逐字节一致 |
| `seedmean` | 同站、同日期、同标签支持下三个种子的预测算术平均，再计算指标 |
| `joint` | 共同日模型：同一日预测聚合至官方月均，并计算HF月内异常目标 |
| `fixed_recipe` | 与空间配置0及固定训练轮数匹配的全域参照，不是新增搜索候选 |
| `same_recipe_global_training_reconstruction` | 同配方全域模型对2023的训练重建，不能称为留出预测 |
| `same_recipe_global_forecast` | 同配方全域模型对2024的预测；与区域留出比较仍须说明训练区域差异 |
| `aux` / `lead1`、`lead7`、`lead30` | 历史TN辅助路线及提前量；日为1/7/30日，月路线的`lead1`为一个公历月 |
| `closed_loop` | 年度冻结模型就绪后不再读取评价年实测TN或其缺测状态，以预测反馈推进 |
| `reference_U` / `reference_LAND1` | 旧灰箱冻结T0入口0的描述性对照；来源、历史及目标不同 |
| `reference_old_tree_A0` | 旧提升树对照，包含D29派生特征，不能称为本轮的独立输入纯ML |

本轮内部验证冻结的直接路线为官方月报CatBoost配置2、HF日TN CatBoost配置4；联合路线为XGBoost配置7、Transformer配置3和GraphTCN配置7。空间路径固定配置0，不把全域内部验证的最佳配置搬入空间留出。最终冻结清单由`outputs/frozen_selection.json`、`outputs/frozen_joint_selection.json`及`outputs/result_roles.json`登记，不按2023/2024成绩更改。

## 三种月/日支持不能混用

| 读出 | 标签与预测支持 | 解释边界 |
| --- | --- | --- |
| `monthly`直接月预测 | 官方有效月报，逐站月一个标签 | 树/MLP使用月均驱动；序列路线使用截至月末的日窗口，输入表示并不相同 |
| `monthly`联合日聚合/`dailyagg` | 全日历日预测的等日月均与官方月报配对 | 月报来自自动监测有效读数算术均值；完整读数次数未知时等日近似未认证为相同采样算子 |
| `hf_monthly` | HF共同合格日期，按实际有效读数次数聚合预测和TN | 是HF支持月值，不冒称官方完整月报 |
| `daily` | 合格HF日均，每日一个过程标签 | 不把同一天六个读数当六个独立日过程样本，不把月报复制成日TN |
| `month_centered` | 每站月内按有效读数次数去均值，再以月份等权累计误差和观测方差 | 只检验已观测日上的月内形状；不是四小时日内模拟 |

所有TN单位为mg N/L。日NSE至少需要30个共同有效日及3个月；月NSE至少需要8个共同站月；零观测方差保持不可定义。原始逐站表仍保留覆盖不足或零方差站，不能只保留高分站。总体中位数之差和逐站配对差中位数分别计算，并列共同合格站数与改善比例。

事件以冻结观测日期和共同背景支持比较。峰日只在原始观测峰仍在共同支持、且观测及两预测都具有唯一峰时判读；平坦或并列峰不认证相位改善。重采样共享同一日历月/连续两月抽样序列，跨站同步，seed1729、各1000次；不是独立逐站抽样。

## 输入可见性和模型解释

主线只有冻结H1水文、气象和独立土地/土壤/地形/河网/农业/沉降/MOD17产品，不使用D29或LAND1的预测、库存、拟合倍率、反推来源、可训练站号，NH₄和DO均排除。139个原始输入通道另有缺失掩码；GraphTCN额外接收冻结上游一跳的邻居平均特征，因此与普通网络不具有完全相同的输入视图。

H1从1961年连续演化；ML使用2015—2024驱动、90/180/365日显式窗口及过去365日滚动特征。不能把水文暖机解释为纯ML具有1961起的氮库存，也不能说最长模型只看365日信息。230河段全域读出是无标签区域外推，认证评价仍限于116个月度站和15个HF站。

当期年度产品及当月沉降为回顾性已知条件，不等于业务预报起点已取得资料。四个沉降特征是当月非水面暴露量kg N/ha/month，排除水面class5，包含未知土地class0的产品估计暴露；不是逐日湿沉降负荷。MOD17是碳生产特征，不是新增外部氮源。资料情景、年份供体和缺项身份见输入登记及实际方法说明。

历史TN辅助是另一证据线，采用严格起点以前可见的读数和捕获时间；月报次月初可见尚为条件假设。模型就绪时点固定为评价年1月2日，日提前1/7/30日最早目标日分别为1月3日、1月9日、2月1日，月提前一个月最早覆盖3月。滚动更新与年度闭环必须同时和同可见性持续性基线比较；反馈收益不能解释为外部氮源可预测性。

纯ML不强制氮质量守恒。特征重要性、置换依赖和时间高分不能证明物理因果，也不能替代未见支流检验。新旧灰箱与旧提升树只作完整配置的描述性对照。

## 运行、停止与交付身份

本机RTX4060 Ti 16GB负责已登记的九条Graph空间路径，单GPU、宿主单线程；工作站RTX5090 D 32GB承担批量网络路线，CPU模型使用经测速的线程/并发组合。名义上限、已创建PID、已取得租约和实际计算分开登记；宿主提交内存和显存是不同的资源门。

patience、固定epoch和树数上限都是停止规则，不认证优化充分收敛。检查点同时保存模型、优化器、随机状态、训练轮次和输入/任务身份。恢复与回传不重训已经完成的同ID模型。最终以冻结预测、完整尝试清单、独立指标复算与专家解读共同签署，不能以控制器退出或归档成功代替科学报告完成。
